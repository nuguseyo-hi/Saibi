## 개정판 — 인형극 프롤로그와 텍스트 기반 심상던전

# 0. 프로젝트 및 작업 지침

현재 개발 중인 React + TypeScript 기반 웹 비주얼노벨 게임 《니알라토텝의 사도》(가제)의 프롤로그와 심상던전을 구현 및 보강하려고 합니다.

기존 게임에는 비주얼노벨 대화 시스템, 캐릭터 상태 관리, 낮/밤 진행, 고해성사, 사고 편집, Phaser 기반 심상던전 등의 시스템이 존재하거나 개발 중입니다.

**이 기획서의 목표는 기존 프롤로그 시나리오를 유지하면서, 심상던전의 텍스트 상호작용을 게임의 핵심 메카닉으로 발전시키는 것입니다.**

특히 다음 세 게임의 특징을 참고합니다.

- Epistory – Typing Chronicles: 기억의 발견에 따라 종이 공간이 접히고 펼쳐지는 연출
- Typoman: 글자 자체가 지형, 장애물, 적으로 기능하는 시스템
- Word Game (文字遊戲): 문자를 조작하면 실제 게임 세계의 규칙이 바뀌는 시스템

위 작품의 구체적인 그래픽, 캐릭터, 레벨, 리소스는 복제하지 않고 시스템적 특성만 참고하여 독창적인 게임을 제작합니다.

# 1. 게임의 핵심 콘셉트

플레이어는 외신 니알라토텝의 개입으로 탄생한 최초의 사도가 되어 변방 마을 세루스에 도착합니다.

낮에는 마을을 조사하며 주민들의 사건과 인간관계를 알아내고, 밤에는 교회에 찾아온 사람들의 고해성사를 듣습니다.

캐릭터의 경계도가 20 이하로 낮아지면 정신 침투가 가능해집니다.

정신 침투에 성공하면 해당 인물의 심상세계에 입장합니다.

심상세계는 인물의 기억, 감정, 가치관, 신념이 공간으로 실체화된 장소입니다.

심상세계에서는 다음 현상이 발생합니다.

- 기억은 종이 조각으로 존재합니다.
- 문장은 실제 지형을 구성합니다.
- 글자의 형태와 서식은 물리적 성질을 결정합니다.
- 부정적인 단어는 살아 움직이는 적이 될 수 있습니다.
- 문장을 수정하면 공간의 규칙이 변화합니다.
- 기억을 발견하면 새로운 지형이 펼쳐집니다.
- 인물의 핵심 신념은 편집에 저항할 수 있습니다.

던전의 중심에 도달하면 핵심 사고 편집을 진행할 수 있습니다.

## 1.1 프롤로그의 특수성

프롤로그는 본편과 달리 외신 니알라토텝이 직접 개입하는 특별한 튜토리얼입니다.

프롤로그에서 플레이어는 니알라토텝의 안내를 받는 관객입니다.

관객은 무대 위 인물의 정신을 수정하는 과정을 경험합니다.

이때 정신을 수정당하는 금발 인물은 본래 태양신을 섬기던 이단심문관입니다.

그는 동료에게 배신당한 뒤 폐허에 홀로 남겨졌으며, 니알라토텝의 권능으로 자신의 정체성을 왜곡당합니다.

**프롤로그 종료 후 플레이어는 바로 이 금발 인물을 직접 조작하게 됩니다.**

이 사실은 이후 메인 스토리의 중요한 반전과 연결됩니다.

# 3. 프롤로그 장면 1 — 세계의 창조

## 배경

고전 극장의 무대.

붉은 커튼이 열리면 조잡한 종이 인형들이 태양신의 창조 신화를 연기합니다.

인형을 조종하는 사람은 정확히 보이지 않습니다.

무대 뒤의 실루엣과 손만 보입니다.

나레이터는 이 인물을 통해 세계를 설명합니다.

실제 정체는 니알라토텝이지만, 해당 사실을 게임 화면에 명시적으로 표시하지 않습니다.

## 시각 연출

- 붉은색과 황금색의 극장 커튼
- 원색을 많이 사용하는 과장된 색채
- 조잡한 종이 인형
- 인형을 매단 실
- 부자연스러운 인형 움직임
- 무대 뒤의 거대한 그림자
- 간헐적인 글리치 효과
- 인형을 조종하는 거대한 손

# 6. 대화 키워드 수집

플레이어는 금발 인물에게 세 가지 질문을 할 수 있습니다.

질문은 원하는 순서대로 진행할 수 있으며, 세 질문을 모두 완료하면 다음 단계로 진행합니다.

수집 키워드:

- 동료
- 배신
- 공적

## 키워드 UI

- [ ]는 시나리오 데이터에서 키워드를 지정하기 위한 표기입니다.
- 실제 화면에는 대괄호를 표시하지 않습니다.
- 키워드에 마우스를 올리면 색상이 변화합니다.
- 키워드를 클릭하면 수집됩니다.
- 수집된 키워드는 별도의 키워드 목록에 보관됩니다.
- 키워드는 심상던전의 퍼즐에 사용됩니다.
- 이미 수집한 키워드는 중복 획득할 수 없습니다.

키워드가 미수집 상태여도 진행이 영구적으로 막히지 않도록, 던전에서 다시 획득할 수 있는 대체 경로를 제공합니다.

## 질문 종료

나레이션:
"이 정도면 이 어린 양을 구원하기에는 충분하고도 넘치는 정보네요. 그러면 슬슬, 그의 마음을 들여다볼까요?"

이후 금발 인물에게 마우스를 올리면 화면이 어두워지고 스포트라이트가 비춰집니다.

캐릭터를 클릭하면 정신 침투를 시작합니다.

위에서 아래로 조잡한 털실 질감의 커튼이 내려오고, 완전히 덮인 뒤 빠르게 걷히면서 심상던전으로 전환됩니다.

# 7. 심상던전의 핵심 시스템

이번 개정판에서 가장 중요한 부분입니다.

심상던전은 단순히 텍스트 퍼즐이 배치된 던전이 아닙니다.

**문자 자체가 지형이고, 문장은 게임 세계의 법칙이며, 기억의 발견은 공간의 확장을 의미합니다.**

세 개의 주요 시스템을 구현합니다.

1. 텍스트의 물리화
2. 문장 편집과 환경 변화
3. 종이 콜라주와 공간 확장

여기에 문자형 적과 자아의 저항 시스템을 결합합니다.

---

# 8. 시스템 A — 텍스트의 물리화

## 8.1 기본 개념

심상세계에 나타나는 텍스트는 실제 게임 오브젝트로 기능할 수 있습니다.

글자의 크기, 서식, 형태, 의미에 따라 물리적인 성질이 달라집니다.

초기에는 글자 하나하나를 별도의 물리 오브젝트로 만들지 않고 단어 또는 문장 블록을 하나의 충돌 오브젝트로 처리합니다.

## 8.2 텍스트 서식 규칙

### 굵은 글씨

굵은 글씨는 단단한 물체입니다.

예시:
**절대로**

- 플레이어가 통과할 수 없는 벽
- 무거운 장애물
- 공간을 가로막는 구조물

### 밑줄

밑줄은 밟을 수 있는 길이나 다리가 됩니다.

예시:
밑줄이 그어진 문장이 복도 사이를 연결합니다.

- 통행 가능한 길 생성
- 끊어진 공간 연결
- 밑줄이 사라지면 통로도 사라짐

탑다운 시점에서는 발판보다 다리나 통로 형태로 구현합니다.

### 취소선

취소선이 적용된 텍스트는 존재가 불안정합니다.

예시:
'거짓'이라는 글자에 취소선이 적용되어 있습니다.

- 글자는 보이지만 충돌하지 않음
- 플레이어가 통과 가능
- 다른 문장에 의해 취소선이 제거되면 다시 장애물이 됨

### 괄호

괄호는 다른 공간을 감싸는 경계입니다.

- 괄호 안에 들어가면 별도의 기억 영역에 진입
- 괄호 안에서 배경 색이나 텍스트가 변화
- 초기에는 하나의 상호작용 영역으로 구현

### 문장부호

문장부호는 텍스트의 행동과 상태를 바꿉니다.

느낌표(!):

- 강한 반응
- 공격성
- 돌진

물음표(?):

- 불확실성
- 망설임
- 행동 일시정지

말줄임표(…):

- 지연
- 반복
- 공간 확장

초기에는 느낌표와 물음표의 차이를 우선 구현합니다.

## 8.3 구현 원칙

텍스트의 시각적 서식과 충돌 판정은 서로 연결되어야 합니다.

예를 들어 굵은 글씨를 취소선 상태로 변경했다면:

1. 텍스트 렌더링 변경
2. 해당 오브젝트의 충돌 판정 해제
3. 플레이어가 통과 가능
4. 편집 취소 시 충돌 판정 복구

이 동작을 공통 시스템으로 구현해 주세요.

---

# 9. 시스템 B — 문장 편집과 환경 변화

## 9.1 기본 개념

심상세계의 문장은 실제 공간의 규칙을 정의합니다.

플레이어는 특정 단어나 문장을 수정하여 해당 규칙을 변경할 수 있습니다.

문장 수정은 단순한 텍스트 변경이 아니라 실제 게임 환경의 상태 변경으로 이어집니다.

## 9.2 환경 편집 유형

초기에는 다음 기능을 지원합니다.

### 단어 삽입

빈 문장에 수집한 키워드를 배치합니다.

예시:

"나는 [　　　]를 믿었다."

'동료' 삽입:

"나는 동료를 믿었다."

결과:
종이 다리가 펼쳐집니다.

### 단어 치환

특정 단어나 구절을 다른 것으로 변경합니다.

예시:

"이 문은 절대로 열리지 않는다."

편집 가능한 구절:

- 절대로 열리지 않는다.
- 잠시 후 열린다.
- 이미 열려 있다.

결과:

- 절대로 열리지 않는다: 문 유지
- 잠시 후 열린다: 일정 시간 후 문 열림
- 이미 열려 있다: 즉시 문 열림

### 부정어 분리

문장에 붙어 있는 부정어를 분리합니다.

예시:

"여기가 출구다."

'아니야'라는 적대적 문자가 문장에 달라붙으면 출구가 비활성화됩니다.

해당 문자를 분리하면 출구가 다시 나타납니다.

### 문장 재배열

여러 문장의 순서를 변경합니다.

이번 프롤로그에서는 두 문장의 순서 변경을 통해 결과가 변화하는 간단한 예시만 구현합니다.

## 9.3 구현 방식

자연어의 의미를 실시간으로 분석할 필요는 없습니다.

각 문장과 편집 결과에 ID를 부여합니다.

예시:

- sentence_id
- editable_segment_id
- replacement_option_id
- result_id
- environment_event_id

편집 결과 ID에 따라 다음 이벤트가 실행되도록 합니다.

- 문 열기
- 문 닫기
- 충돌 영역 제거
- 새로운 다리 생성
- 적 행동 변경
- 종이 공간 펼치기
- 기억 오브젝트 표시
- 저항 이벤트 실행

문장의 문자열 자체를 코드에서 비교하는 방식은 피합니다.

---

# 10. 시스템 C — 종이 콜라주와 공간 확장

## 10.1 기본 개념

심상세계는 처음부터 완성된 공간이 아닙니다.

기억이 종이 조각처럼 접히거나 겹쳐져 있으며, 기억을 발견할수록 새로운 공간이 펼쳐집니다.

## 10.2 종이 펼치기

기억을 발견하면 다음 연출이 발생합니다.

1. 기억을 상징하는 종이 오브젝트가 움직입니다.
2. 종이가 확대됩니다.
3. 접힌 부분이 펼쳐집니다.
4. 새로운 배경과 바닥이 드러납니다.
5. 해당 공간의 충돌 영역과 통로가 활성화됩니다.

실제 복잡한 종이접기 물리 시뮬레이션은 사용하지 않습니다.

Phaser의 스케일, 마스크, 회전, 트윈 애니메이션과 이미지 레이어를 활용합니다.

## 10.3 종이 뒤집기

일부 종이에는 앞면과 뒷면이 존재합니다.

앞면과 뒷면에는 서로 다른 기억이 기록되어 있습니다.

예시:

앞면:
"나는 그날 밤 아무도 만나지 않았다."

뒷면:
"나는 그날 밤 누군가와 약속했다."

종이를 뒤집으면 새로운 문장이 나타납니다.

이때 플레이어는 두 문장의 모순을 발견할 수 있습니다.

프롤로그에서는 제2구역의 신성한 문장을 통해 이 기능을 소개합니다.

## 10.4 공간의 콜라주 표현

다음 시각 요소를 조합합니다.

- 거친 종이 질감
- 흑백 판화
- 컬러 인형
- 손으로 오린 듯한 장식
- 서로 다른 글꼴
- 비정상적인 원근감
- 과장된 원색
- 종이 인형의 부자연스러운 움직임
- 겹쳐지는 배경 레이어

실제 아트 리소스가 없는 경우 플레이스홀더로 구현합니다.

배경과 개별 오브젝트를 교체할 수 있도록 이미지 리소스를 분리해 주세요.

# 11. 시스템 D — 문자형 적

문자형 적은 특정한 의미를 가진 글자들이 살아 움직이는 존재입니다.

프롤로그에서는 두 가지 행동을 소개합니다.

## 적 A — 배신

제1구역에 등장합니다.

- 플레이어에게 접근
- 일정 거리에서 빠르게 이동
- 충돌 시 침투 안정도 감소
- 공격 전 글자가 흔들림

프롤로그의 기본 적입니다.

## 적 B — 거부의 문자

'싫어!'라는 단어를 사용합니다.

- 플레이어를 향해 돌진
- 느낌표가 커지면서 공격 예고
- 충돌 시 침투 안정도 감소

문장부호를 수정할 수 있습니다.

'싫어!' → '싫어?'

변경 후:

- 돌진 행동 중단
- 움직임이 느려짐
- 일정 시간 망설임
- 이후 느린 배회 상태로 전환

## 적 C — 아니야

문장과 결합하는 특수 문자입니다.

- 특정 문장에 접근
- 문장 앞에 달라붙음
- 문장의 의미를 부정하는 이벤트 발생
- 관련 환경 오브젝트의 상태가 변화

이번 프롤로그에서는 필수 전투 적이 아니라 간단한 환경 이벤트로만 구현해도 됩니다.

## 전투 난이도

프롤로그에서는 적을 직접 공격해 제거하는 전투 시스템을 만들지 않습니다.

회피와 텍스트 조작에 집중합니다.

침투 안정도는 기존 시스템을 활용하고, 튜토리얼 진행이 영구적으로 막히지 않도록 재시도할 수 있게 해 주세요.

# 12. 시스템 E — 자아의 저항

## 12.1 기본 개념

캐릭터의 심상세계는 플레이어의 개입을 무조건 받아들이지 않습니다.

핵심 신념과 충돌하는 편집을 시도하면 심상세계가 저항합니다.

## 12.2 저항 연출

다음 문장을 수정한다고 가정합니다.

원본:
"나는 그날 밤 아무도 만나지 않았다."

수정:
"나는 그날 밤 누군가를 만났다."

주변에 새로운 문장들이 등장합니다.

- 아니야.
- 그런 일은 없었어.
- 나는 분명 혼자였어.

이 문장들은 단순한 배경 텍스트가 아닙니다.

일부는 장애물이 되고, 일부는 플레이어를 방해하는 문자형 적이 됩니다.

## 12.3 저항도

기존 경계도와 별개로 정신세계 내부의 저항도를 관리합니다.

- 경계도: 현실에서 플레이어를 경계하는 정도
- 저항도: 정신세계가 편집에 반발하는 정도
- 침투 안정도: 던전 탐험 중 플레이어의 자원

프롤로그에서는 자아의 저항이 발생해도 나레이터가 이를 강제로 무력화합니다.

본편에서는 강한 저항으로 정신 침투에 실패할 수 있습니다.

이번 단계에서는 저항도에 따른 문장 생성과 환경 변형을 우선 구현합니다.

# 13. 프롤로그 심상던전 전체 구성

## 던전 이름

**최초의 침투 — 이름 없는 사도의 내면**

총 세 개의 구역으로 구성합니다.

세 구역은 텍스트 편집의 영향력이 점점 커지는 순서로 배치합니다.

- 제1구역: 텍스트는 사물이다.
- 제2구역: 텍스트는 세계의 법칙이다.
- 제3구역: 텍스트는 정체성이다.

# 14. 제1구역 — 배신의 회랑

## 학습 목표: 텍스트는 사물이다

## 14.1 배경

찢어진 성서, 낡은 종이, 인형극 무대 장치로 구성된 복도입니다.

바닥에는 다음 문장들이 흩어져 있습니다.

"믿었는데."

"함께 싸웠는데."

"어째서?"

"배신."

"배신."

"배신!"

## 14.2 텍스트 지형

복도에는 다음 요소가 존재합니다.

### 굵은 글자의 벽

거대한 **절대로**라는 글자가 통로를 가로막습니다.

플레이어는 이를 통과할 수 없습니다.

### 밑줄의 다리

끊어진 복도 사이에 밑줄이 그어진 문장이 있습니다.

밑줄은 실제 이동 가능한 통로로 취급합니다.

### 취소선의 벽

취소선이 적용된 '거짓'이라는 글자가 있습니다.

겉으로는 벽처럼 보이지만 플레이어가 통과할 수 있습니다.

이 구역에서 플레이어는 글자의 형태가 물리적 성질과 연결된다는 사실을 학습합니다.

## 14.3 문자형 적

'배신'과 '싫어!'가 등장합니다.

'배신'은 기본적인 이동과 회피를 학습시키는 적입니다.

'싫어!'는 텍스트 수정으로 행동이 변화하는 적입니다.

플레이어가 문장부호 수정 기능을 사용해 '싫어!'를 '싫어?'로 변경하면 적이 돌진을 멈춥니다.

이 기능은 튜토리얼이므로 적이 멈춘 상태에서 쉽게 편집할 수 있도록 합니다.

## 14.4 핵심 퍼즐 — 믿음의 다리

끊어진 다리 앞에 다음 문장이 나타납니다.

"나는 [　　　]를 믿었다."

플레이어는 앞서 수집한 '동료' 키워드를 빈칸에 삽입합니다.

결과:

"나는 동료를 믿었다."

### 환경 변화

1. 문장이 완성됩니다.
2. 글자가 빛납니다.
3. 접혀 있던 종이 조각이 펼쳐집니다.
4. 종이 다리가 생성됩니다.
5. 실제 충돌 영역이 활성화됩니다.
6. 플레이어가 다음 구역으로 이동할 수 있게 됩니다.

## 14.5 기억 연출

다리를 건너면 종이 인형 두 개가 등장합니다.

두 인형이 나란히 싸우다가 한 인형이 등을 돌리고 떠납니다.

인형을 조종하는 실이 끊어지고 무대 일부가 무너집니다.

나레이션:
"아하, 이제 알겠군요! 이 가엾은 양의 마음에는 배신이라는 단어가 아주 깊숙이 박혀 있네요."

나레이션:
"정말이지, 인간이란 얼마나 어리석은 생물인지! 타인을 믿을 수 있다고 생각하다니 말이에요!"

나레이션:
"자, 관객 분. 다음 장면으로 넘어가 볼까요?"

# 15. 제2구역 — 응답 없는 예배당

## 학습 목표: 텍스트는 세계의 법칙이다

## 15.1 배경

이전 구역과 달리 정돈되고 아름다운 황금빛 성당입니다.

- 대칭적인 건축 구조
- 황금빛 스테인드글라스
- 태양신의 성표
- 정렬된 문장
- 신성한 봉인
- 고요한 음악

인물의 강한 신앙을 상징합니다.

## 15.2 신성한 문장

중앙에 다음 문장이 존재합니다.

"나는 태양의 신을 믿는다."

"태양의 신은 나를 지켜줄 것이다."

문장은 황금빛으로 표현합니다.

첫 번째 문장은 핵심 신념이므로 플레이어가 편집할 수 없습니다.

클릭하면 신성한 봉인에 의해 보호받고 있다는 반응이 나타납니다.

## 15.3 환경 퍼즐 — 응답하지 않는 신

성당의 제단 앞에는 다음 문장이 존재합니다.

"하지만 신은 응답하지 않았다."

해당 문장으로 인해 제단으로 향하는 통로가 닫혀 있습니다.

플레이어는 단어와 문장의 상태를 조사하여 통로를 열려고 시도합니다.

### 1단계: 부정어 분리

'아니야'라는 단어가 주변 문장에 달라붙어 있습니다.

플레이어는 이를 분리하여 일시적으로 통로 일부를 활성화합니다.

### 2단계: 문장 치환

다른 문장에서는 정해진 선택지로 문장을 수정할 수 있습니다.

예시:

"이 문은 절대로 열리지 않는다."

변경 가능한 문장:

- 절대로 열리지 않는다.
- 잠시 후 열린다.
- 이미 열려 있다.

플레이어가 문장을 수정하면 실제 문 오브젝트의 상태와 충돌 판정이 변화합니다.

이 퍼즐은 플레이어에게 텍스트가 세계의 규칙을 변경한다는 사실을 알려줍니다.

### 3단계: 핵심 신념의 봉인

그러나 가장 깊은 제단의 문장은 수정할 수 없습니다.

플레이어가 편집을 시도하면 황금빛 봉인이 나타납니다.

여기서 나레이터가 개입합니다.

나레이션:
"어머나! 꽤나 독실한 신도인 모양이에요."

나레이션:
"하지만 이런 낡아빠진 맹세 때문에 이야기가 멈춰서야 되겠어요?"

나레이션:
"관객 분, 제가 조금 도와드릴까요?"

거대한 손이 나타나 봉인된 문장을 집어 듭니다.

마치 종이를 찢듯 문장을 해체합니다.

## 15.4 종이 뒤집기 복선

찢어진 문장의 뒷면에 잠깐 다음 문장이 나타납니다.

"신은 나를 버리지 않았다."

이는 나레이터의 손에 가려져 곧 사라집니다.

해당 문장은 이후 스토리의 복선입니다.

게임에서 직접 설명하지 않습니다.

## 15.5 환경 변화

- 신성한 문장이 찢어집니다.
- 금빛 제단의 색이 변합니다.
- 문장의 글자들이 흩어집니다.
- 접혀 있던 제단 뒤의 종이 공간이 펼쳐집니다.
- 새로운 통로가 생성됩니다.
- 최심부로 이동할 수 있게 됩니다.

# 16. 제3구역 — 이름 없는 제단

## 학습 목표: 텍스트는 정체성이다

## 16.1 배경

검은 공간 중앙에 황금빛 제단이 떠 있습니다.

제단 주변에는 종이 인형과 끊어진 실들이 떠다닙니다.

중앙에는 금발 인물의 정체성을 이루는 세 개의 핵심 문장이 존재합니다.

## 16.2 핵심 사고

1. "나는 태양의 신을 섬긴다."
2. "나는 신의 적을 심판한다."
3. "나는 나의 사명을 완수해야 한다."

각 문장은 독립적인 사고 노드로 관리합니다.

## 16.3 문장 재구성 퍼즐

이 구역에서는 단순한 단어 치환과 함께 문장 재배열 기능을 소개합니다.

플레이어는 앞서 얻은 키워드를 사용해 문장의 일부를 변경할 수 있습니다.

예시:

- 태양의 신
- 사도
- 배신

단, 모든 편집이 성공하지는 않습니다.

신성한 문장에는 봉인이 존재합니다.

또한 금발 인물의 정체성과 충돌하는 문장을 만들면 심상세계의 저항이 발생합니다.

### 문장 재배열

세 개의 문장을 각각 하나의 사고 블록으로 표시합니다.

플레이어는 처음 두 문장의 순서를 변경할 수 있습니다.

순서를 바꾸면 제단의 조명과 인형의 배치가 변화합니다.

이때 문장 순서 변경은 튜토리얼용이며, 프롤로그의 최종 결과 자체는 바꾸지 않습니다.

## 16.4 자아의 저항

플레이어가 핵심 신념을 변경하려고 하면 다음 문장들이 나타납니다.

"아니야."

"거짓말."

"나는 누구인가?"

"나는 신을 섬긴다."

문장들이 충돌하면서 심상세계가 불안정해집니다.

일부 문장은 벽이 되고, 일부는 플레이어 주변을 움직입니다.

제단의 금빛 문장은 플레이어의 편집을 거부합니다.

## 16.5 나레이터 개입

나레이션:
"아아, 또다시 거부하는군요! 참으로 완고한 아이이지 않나요?"

나레이션:
"하지만 걱정 마세요. 관객 분이 직접 모든 걸 해결해야 할 필요는 없답니다."

나레이션:
"자, 이제 마지막 한 줄만 고쳐볼까요?"

화면 밖에서 거대한 손이 나타납니다.

손이 사고 블록을 집어 들고 문장을 강제로 해체합니다.

수정 전:

"나는 태양의 신을 섬긴다."

수정 후:

"나는 ■■■■■■■의 사도다."

이때 신의 이름은 가려진 상태로 표시합니다.

세 번째 문장은 그대로 남깁니다.

"나는 나의 사명을 완수해야 한다."

### 핵심 의도

금발 인물의 사명감은 그대로 남아 있습니다.

다만 그 사명이 향하는 대상과 자기 정체성이 변경된 것입니다.

이것이 본래 이단심문관이었던 인물이 외신의 사도가 되는 핵심적인 변화입니다.

## 16.6 최종 연출

1. 제단이 검게 변합니다.
2. 문장이 여러 글자로 분해됩니다.
3. 문장의 글자가 공중에 떠오릅니다.
4. 검은 실들이 내려옵니다.
5. 실들이 금발 인물의 인형과 연결됩니다.
6. 주변의 저항하는 문장들이 사라집니다.
7. 새로운 문장이 완성됩니다.
8. 화면 전체가 암전됩니다.

해당 인물의 정체를 직접 설명하지 않습니다.

# 20. 편집 데이터와 상태 복원

이번 작업에서 중요한 것은 문장 편집의 결과와 실제 환경 변화가 일치하도록 만드는 것입니다.

모든 편집 가능 구간에는 고유 ID를 부여합니다.

자연어 전체를 자유롭게 분석하지 않고 사전에 정의된 결과에 따라 게임 상태를 변경합니다.

## 환경 편집

던전 내부의 문장 수정입니다.

예시:

- 문장 수정
- 문 열림
- 다리 생성
- 적 행동 변경

환경 편집 결과는 던전 진행 상태에 저장합니다.

편집을 취소하면 관련 환경 오브젝트도 원래 상태로 복원되어야 합니다.

## 핵심 사고 편집

최심부에서 캐릭터의 정체성을 변경하는 편집입니다.

이 결과는 캐릭터의 장기적인 상태와 이후 시나리오에 영향을 줍니다.

기존 사고 편집 시스템을 재사용해 주세요.

## 상태 처리 원칙

- 임시 편집과 확정된 편집을 분리합니다.
- 동일한 환경 이벤트가 중복 실행되지 않도록 합니다.
- 문장 상태와 충돌 상태가 서로 불일치하지 않아야 합니다.
- 재입장 시 저장된 진행 상태를 복원할 수 있어야 합니다.
- 대사 스킵이나 애니메이션 건너뛰기로 필수 상태 변화가 누락되지 않아야 합니다.
- React와 Phaser 사이에 이벤트 리스너가 중복 생성되지 않도록 합니다.
- Phaser 오브젝트의 매 프레임 위치를 Zustand에 저장하지 않고 의미 있는 게임 이벤트만 공유합니다.

# 21. 프롤로그의 난이도와 튜토리얼 원칙

프롤로그는 실제 외신이 직접 개입하는 장면입니다.

따라서 본편보다 쉽고 간단하게 구성합니다.

### 프롤로그

- 경계도가 강제로 0으로 변경됨
- 사고 편집이 쉽게 성공함
- 핵심 기억의 봉인을 나레이터가 해체함
- 자아의 저항을 나레이터가 무력화함
- 최종 결과는 최초의 사도 탄생으로 고정됨

### 본편

- 경계도 20 이하에서만 정신 침투 가능
- 문장 편집에 제한이 존재함
- 핵심 기억에 대한 저항 발생
- 침투 실패 가능
- 캐릭터마다 다른 사고 편집 결과 존재

이번 프롤로그에서는 게임 오버로 영구적인 진행 불가 상태가 발생하지 않도록 합니다.

퍼즐 실패 시 재시도할 수 있게 해 주세요.

# 22. 그래픽 구현 방향

현재 게임에 완성된 아트 리소스가 없다면 임시 리소스를 사용합니다.

단, 다음 연출은 가능한 한 실제로 동작하도록 구현해 주세요.

1. 커튼이 내려오고 올라가는 연출
2. 인형의 부자연스러운 움직임
3. 글자의 글리치와 강제 수정
4. 거대한 손의 개입
5. 텍스트 지형의 충돌
6. 문장 수정에 따른 지형 변화
7. 종이 다리 펼치기
8. 종이 앞면과 뒷면 전환
9. 적대적인 글자의 움직임
10. 자아의 저항에 따른 문장 생성
11. 심상세계가 접히며 사라지는 연출
12. 플레이어 캐릭터 전환

완성된 일러스트 제작은 이번 작업의 범위에 포함하지 않습니다.

개발용 임시 이미지나 도형으로 구현하고, 이후 실제 이미지를 쉽게 교체할 수 있도록 만들어 주세요.

과도한 글리치와 빠른 점멸은 피하고 연출 강도를 낮출 수 있도록 고려해 주세요.

- 프롤로그 시나리오 데이터

- 경계도 UI
- 경계도 강제 변경

## STEP 3 — 키워드 수집

- 반복 가능한 질문
- 키워드 강조

- 키워드 목록

## STEP 4 — 텍스트 물리화

- 밑줄 통로

## STEP 5 — 문장과 세계의 상호작용

- 단어 삽입
- 단어 치환
- 부정어 분리
- 문장 재배열
- 문장 상태에 따른 환경 이벤트

## STEP 6 — 종이 콜라주 연출

- 종이 펼치기
- 종이 뒤집기

# 25. 완료 기준

아래 항목을 모두 검증해 주세요.

## 프롤로그

- 고전 인형극으로 시작한다.
- 나레이터의 정체가 직접 노출되지 않는다.
- '아니요' 선택지가 강제로 수정된다.
- 인형극에서 비주얼노벨로 전환된다.
- 경계도가 90 → 100 → 0으로 변화한다.
- 키워드를 클릭하여 수집할 수 있다.
- 정신 침투 연출이 실행된다.

## 심상던전

- 플레이어가 실제로 이동할 수 있다.
- 텍스트가 충돌 가능한 지형으로 기능한다.
- 굵은 글씨, 밑줄, 취소선의 물리적 성질이 구분된다.
- 문자형 적이 움직인다.
- 문장부호 변경으로 적의 행동이 바뀐다.
- 키워드 삽입으로 종이 다리가 생성된다.
- 문장 치환으로 문이 열린다.
- 부정어 분리로 환경 상태가 변경된다.
- 종이를 뒤집어 숨겨진 기억을 볼 수 있다.
- 종이 펼치기로 새로운 공간이 나타난다.
- 핵심 신념의 봉인이 작동한다.
- 나레이터가 봉인을 강제로 해체한다.
- 핵심 사고 편집 시 자아의 저항이 발생한다.
- 최종 문장이 수정된다.

## 프롤로그 종료

- 심상던전이 붕괴하는 연출이 실행된다.
- 폐허 장면으로 복귀한다.
- 금발 인물이 최초의 사도가 된다.
- 플레이어의 조작 대상이 금발 인물로 변경된다.
- 제1장 세루스로 연결된다.
- 저장 및 로드가 정상적으로 작동한다.
- 기존 게임 기능이 손상되지 않는다.

## 기술 검증

- TypeScript 타입 검사
- 프로젝트 빌드
- 주요 퍼즐 판정 테스트
- 환경 이벤트 중복 실행 검사
- 편집 취소 시 환경 상태 복구 확인
- Phaser 재진입 시 리소스 정리 확인
- 대사 스킵 시 필수 이벤트 누락 여부 확인

실행 가능한 테스트를 수행하고 실제 결과를 보고해 주세요.

# 26. 최종 개발 요청

위 기획을 기준으로 기존 웹게임 프로젝트의 프롤로그와 심상던전을 구현 및 보강해 주세요.

가장 먼저 현재 코드와 기존 시스템을 분석한 후 다음 내용을 간단히 정리해 주세요.

1. 이미 구현된 기능
2. 이번에 추가할 기능
3. 수정해야 할 기존 파일
4. 새로 생성할 파일
5. 예상되는 기술적 충돌과 해결 방안

그 후 STEP 1부터 순서대로 작업해 주세요.

가능한 한 각 단계가 완료될 때마다 실제 게임을 실행할 수 있는 상태를 유지해 주세요.

기능이 미완성이라면 실제로 동작하지 않는 기능을 완성된 것처럼 설명하지 말고, 임시 구현 또는 미구현으로 명확하게 구분해 주세요.

마지막에는 다음 내용을 보고해 주세요.

- 구현 완료 기능
- 새로 생성한 파일
- 변경한 기존 파일
- React와 Phaser의 연결 구조
- 텍스트 오브젝트 및 문장 규칙 시스템
- 각 퍼즐의 테스트 방법
- 빌드 및 테스트 결과
- 브라우저에서 전체 프롤로그를 플레이하는 방법
- 남은 작업과 개선 사항

**이번 프로젝트에서 가장 중요한 목표는 다음 세 가지입니다.**

**첫째, 텍스트가 실제 사물이 되는 경험.**

**둘째, 텍스트를 편집하면 세계가 달라지는 경험.**

**셋째, 타인의 정체성을 수정하던 플레이어가 바로 그 수정당한 인물로 플레이하게 되는 경험.**

이 세 가지가 프롤로그 전체를 관통하도록 구현해 주세요.
