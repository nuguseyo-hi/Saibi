# 프롤로그 횡스크롤 심상던전 — 취소선 리워크

## 현재 플레이 방식

PC 가로 화면을 우선한다. A/D 또는 좌우 방향키로 걷고 Space로 점프한다. 문장 가까이서 붉은 취소선 가운데를 끌면 위치가, 양 끝을 끌면 길이와 각도가 바뀐다. 단어 전체를 가리면 해당 명사나 동작이 억제된다. 일부만 가리면 황색 표시만 나타나며 효과는 없다. 하나의 긴 선으로 여러 단어를 억제할 수도 있다.

드래그 중에는 지형과 인물 반응을 미리 보여 주고 이동 물리를 멈춘다. 놓을 때 좌표·거리·범위를 검증해 자동 저장한다. 종이 바깥이나 너무 짧은 선은 거절하고 이전 상태로 복귀한다. R 또는 복원 버튼으로 취소선을 떼고 세계를 원상복구한다. 편집 취소·일시정지·창 비활성화는 초안을 폐기한다. 확정 전 초안은 저장하지 않는다.

키보드는 Q로 집기, 1 전체 / 2 첫 끝 / 3 둘째 끝, 방향키로 10px 이동(Shift 병용 1px), Enter로 놓기, Escape로 취소한다. E는 기억·문·제단을 조사한다. 편집 중이 아닐 때 Escape로 일시정지한다. 화면 바깥의 메뉴에 포커스가 있으면 이동하지 않는다.

## 세 구역과 관찰 결과

| 구역 | 문장과 조작 | 환경과 인물의 변화 |
| --- | --- | --- |
| 배신의 회랑 | 동료는 나를 가로막는다 / 기억은 다리를 지탱한다 | ‘가로막는다’를 억제하면 벽만 해제된다. ‘동료’는 벽과 동료의 형상을 지우고 얼굴에 대한 기억을 잃게 한다. ‘나’를 지우면 금발 인물도 희미해진다. 기억 또는 지탱을 지우면 다리가 사라지거나 내려앉는다. |
| 응답 없는 예배당 | 빛은 문을 잠근다 / 빛은 다리를 지탱한다 | 같은 ‘빛’은 두 문장에서 연결된다. 빛을 지우면 어두워지고 문이 풀리지만 다리도 끊기며 숨은 기억이 보인다. ‘잠근다’는 빛과 다리를 보존하며 잠금만 해제한다. ‘문’ 자체를 지우는 경로도 유효하다. |
| 이름 없는 제단 | 나는 태양의 신을 섬긴다 / 의심은 나를 붙잡는다 | ‘나’는 자아를 흐리게 하지만 개종을 완료하지 못한다. ‘붙잡는다’는 인형줄과 자세를 풀어도 신앙은 남긴다. 자아를 보존한 채 ‘태양의 신’ 또는 ‘섬긴다’를 지우면 저항·나레이터 개입 뒤 새 신앙이 들어선다. |

화면 오른쪽 인물은 실제 변화 대상이다. 소멸 시 투명도, 구속 시 기울어진 자세와 실, 신앙 변화 시 색과 붉은 실·눈, 반응 독백으로 결과를 보여 준다. 바뀐 단어에서 인물로 조각이 이동한다. 연출 감소 모드는 입자와 이동 연출을 줄이고 의미 변화는 유지한다. 봉인과 저항에는 거대한 손이 개입한다.

회랑의 기억과 예배당 봉인 나레이션은 유지한다. 예배당은 다리와 문을 통과한 뒤 봉인에서 E로 진행한다. 제단의 새 신앙은 `identity=placed`라는 가역 상태다. R로 원래 신앙을 복구할 수 있으며, 오른쪽 최종 문턱에서 E를 눌러 무대가 접힌 뒤 한 번만 결과를 확정한다. 폐허 귀환·이름 입력·금발 인물 조작 인계·세루스 연결은 유지한다. 기존 에밀리아 던전은 변경하지 않는다.

다리 아래로 추락하면 구역에서 재개한다. 편집 또는 저장 복원으로 발밑 다리가 사라진 경우에는 가까운 안전한 가장자리로 이동시킨다. 해당 가장자리에서도 취소선을 복원할 수 있어 진행이 막히지 않는다.

## 데이터와 모듈 경계

- `src/content/prologue/strikes.json`: 안정적인 단어 ID, 명사 참조/동사 역할, 글자 폭·위치, 종이 범위, 초기 취소선, 인물 독백, 안내 문구.
- `src/prologue/strikes.ts`: JSON 검증, 선분과 단어의 기하학적 피복, 명사 공유, 파생 환경, 구버전 결과를 취소선으로 변환. React·Phaser·Zustand에 의존하지 않는다.
- `src/prologue/StrikeLayer.ts`: 실제 마우스/키보드 편집, 초안, 부분 피복 강조, 연결된 단어의 취소선 표시와 리스너 정리. 단어 클릭으로 정답을 고르는 인터페이스는 사용하지 않는다.
- `src/prologue/SideScrollScene.ts`: 이동·충돌·카메라, 실제 지형 및 인물 연출. 의미 효과는 typed bridge로 전달한다.
- `src/prologue/store.ts`: 편집 가능 거리·진행·좌표 검사, 저장·복원·되돌리기, 저항과 단일 최종 확정.
- `src/prologue/PrologueDungeon.tsx`: 안내·반응·나레이션·일시정지. 편집 초안을 영구 진행에 직접 쓰지 않는다.
- `sideScroll.json` / `sideScroll.ts`: 바닥·충돌·게이트 및 안전 좌표. 이전 슬롯 정의는 알려진 데이터 호환용으로 남아 있지만 현재 퍼즐 화면에는 노출하지 않는다.

수정 전 소스·Git 백업: `/workspace/backups/Saibi-before-strike-20261125T062640Z/`. `manifest.json`과 `RESTORE.md`를 함께 보존한다. 이 백업은 브라우저 localStorage를 포함하지 않는다. 배포 역시 기존 gh-pages 기록 위의 일반 커밋으로 되돌릴 수 있다.

## 검증

`npm test`는 57개 검증을 포함한다. 부분 피복·명사 공유·여러 단어 억제·대안 해법·효과 되돌리기·저장 복원·거리/연출 중 거절·가까운 발판 복구·구버전 마이그레이션·단일 최종 확정과 기존 에밀리아 검증을 포함한다. `npm run build`로 TypeScript와 Vite 빌드를 검사한다.
