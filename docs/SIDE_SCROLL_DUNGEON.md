# 프롤로그 횡스크롤 심상던전 — 회랑 단어 삽입과 취소선

## 현재 플레이 방식

PC 가로 화면을 우선한다. 배신의 회랑에서는 이전 대화에서 얻은 단어를 빈칸으로 끌어 넣거나, 1–5로 단어를 선택하고 문장 가까이서 E로 넣는다. R은 단어 회수다. 대화 키워드 버튼을 누르지 않아도 해당 답변을 읽고 다음으로 넘어가면 키워드가 보관된다. 회랑에는 취소선과 독백 패널을 표시하지 않는다. 배경의 ‘나는 누구도 믿지 않아.’와 ‘그런데 왜?’가 내면을 전달한다.

**프롤로그는 신이 직접 편집을 돕는 구간이므로 편집 횟수가 무제한이다.** 본편의 편집 횟수·회복 방식은 아직 구현하지 않는다. 생명력은 별개이며 ‘태양의 신’을 회랑 다리 문장에 넣으면 1 감소한다. 연출 중 중복 입력은 차감하지 않는다. 0이 되면 회랑 입구에서 생명력 3으로 재시작하고 키워드·완료한 편집은 유지한다.

다음 조작 설명은 예배당·제단의 취소선에 해당한다. A/D 또는 좌우 방향키로 걷고 Space로 점프한다. 문장 가까이서 붉은 취소선 가운데를 끌면 위치가, 양 끝을 끌면 길이와 각도가 바뀐다. 단어 전체를 가리면 해당 명사나 동작이 억제된다. 일부만 가리면 황색 표시만 나타나며 효과는 없다. 하나의 긴 선으로 여러 단어를 억제할 수도 있다.

드래그 중에는 지형과 인물 반응을 미리 보여 주고 이동 물리를 멈춘다. 놓을 때 좌표·거리·범위를 검증해 자동 저장한다. 종이 바깥이나 너무 짧은 선은 거절하고 이전 상태로 복귀한다. R 또는 복원 버튼으로 취소선을 떼고 세계를 원상복구한다. 편집 취소·일시정지·창 비활성화는 초안을 폐기한다. 확정 전 초안은 저장하지 않는다.

키보드는 Q로 집기, 1 전체 / 2 첫 끝 / 3 둘째 끝, 방향키로 10px 이동(Shift 병용 1px), Enter로 놓기, Escape로 취소한다. E는 기억·문·제단을 조사한다. 편집 중이 아닐 때 Escape로 일시정지한다. 화면 바깥의 메뉴에 포커스가 있으면 이동하지 않는다.

## 세 구역과 관찰 결과

| 구역 | 문장과 조작 | 환경과 인물의 변화 |
| --- | --- | --- |
| 배신의 회랑 | 나는 (　)를 믿었다 / 동료를 향한 나의 믿음은 ____으로 돌아왔다 | ‘동료’로 해골 다리를 조립하고 ‘배신’으로 문자 문의 빈 부분을 잇는다. 태양의 신은 태양을 띄우고 생명력 1을 차감한 뒤 거대한 손이 끈다. 다른 단어는 돌아온다. 문을 열면 예배당의 빛과 전환 나레이션으로 이어진다. |
| 응답 없는 예배당 | 빛은 문을 잠근다 / 빛은 다리를 지탱한다 | 같은 ‘빛’은 두 문장에서 연결된다. 빛을 지우면 어두워지고 문이 풀리지만 다리도 끊기며 숨은 기억이 보인다. ‘잠근다’는 빛과 다리를 보존하며 잠금만 해제한다. ‘문’ 자체를 지우는 경로도 유효하다. |
| 이름 없는 제단 | 나는 태양의 신을 섬긴다 / 의심은 나를 붙잡는다 | ‘나’는 자아를 흐리게 하지만 개종을 완료하지 못한다. ‘붙잡는다’는 인형줄과 자세를 풀어도 신앙은 남긴다. 자아를 보존한 채 ‘태양의 신’ 또는 ‘섬긴다’를 지우면 저항·나레이터 개입 뒤 새 신앙이 들어선다. |

예배당·제단에서 화면 오른쪽 인물은 실제 변화 대상이다. 소멸 시 투명도, 구속 시 기울어진 자세와 실, 신앙 변화 시 색과 붉은 실·눈, 반응 독백으로 결과를 보여 준다. 바뀐 단어에서 인물로 조각이 이동한다. 연출 감소 모드는 입자와 이동 연출을 줄이고 의미 변화는 유지한다. 봉인과 저항에는 거대한 손이 개입한다.

회랑에서는 입장 안내, 첫 빈칸 조사, 문자 문 완성, 문 열기 나레이션을 구분한다. 태양 연출 이후 단어는 반환되고 다리 문장은 비워진다. 예배당 봉인 나레이션은 유지한다. 예배당은 다리와 문을 통과한 뒤 봉인에서 E로 진행한다. 제단의 새 신앙은 `identity=placed`라는 가역 상태다. R로 원래 신앙을 복구할 수 있으며, 오른쪽 최종 문턱에서 E를 눌러 무대가 접힌 뒤 한 번만 결과를 확정한다. 폐허 귀환·이름 입력·금발 인물 조작 인계·세루스 연결은 유지한다. 기존 에밀리아 던전은 변경하지 않는다.

다리 아래로 추락하면 구역에서 재개한다. 편집 또는 저장 복원으로 발밑 다리가 사라진 경우에는 가까운 안전한 가장자리로 이동시킨다. 해당 가장자리에서도 취소선을 복원할 수 있어 진행이 막히지 않는다.

## 데이터와 모듈 경계

- `src/content/prologue/corridor.json` / `corridor.ts` / `CorridorLayer.ts`: 회랑의 정확한 문구·빈칸 좌표·기하 검증·해골 조립·배경 독백·문자 문·태양/손 연출. 삽입과 비용 확정은 store가 담당한다.
- `src/content/prologue/strikes.json`: 안정적인 단어 ID, 명사 참조/동사 역할, 글자 폭·위치, 종이 범위, 초기 취소선, 인물 독백, 안내 문구.
- `src/prologue/strikes.ts`: JSON 검증, 선분과 단어의 기하학적 피복, 명사 공유, 파생 환경, 구버전 결과를 취소선으로 변환. React·Phaser·Zustand에 의존하지 않는다.
- `src/prologue/StrikeLayer.ts`: 실제 마우스/키보드 편집, 초안, 부분 피복 강조, 연결된 단어의 취소선 표시와 리스너 정리. 단어 클릭으로 정답을 고르는 인터페이스는 사용하지 않는다.
- `src/prologue/SideScrollScene.ts`: 이동·충돌·카메라, 실제 지형 및 인물 연출. 의미 효과는 typed bridge로 전달한다.
- `src/prologue/store.ts`: 편집 가능 거리·진행·좌표 검사, 저장·복원·되돌리기, 저항과 단일 최종 확정.
- `src/prologue/PrologueDungeon.tsx`: 안내·반응·나레이션·일시정지. 편집 초안을 영구 진행에 직접 쓰지 않는다.
- `sideScroll.json` / `sideScroll.ts`: 바닥·충돌·게이트 및 안전 좌표. 이전 슬롯 정의는 알려진 데이터 호환용으로 남아 있지만 현재 퍼즐 화면에는 노출하지 않는다.

## 저장 호환과 복구

스키마 1, 콘텐츠 버전 `first-act-corridor-4`을 사용한다. `first-act-1`, `first-act-side-2`, `first-act-strike-3`의 알려진 퍼즐 결과를 새 회랑의 삽입 상태와 나머지 취소선 좌표로 변환하며 구역·이야기·개종 결과를 보존한다. 첫 변경 전 원본 저장은 덮어쓰지 않는다. 미지정 버전, 손상 좌표, 취소선과 환경이 불일치하는 저장은 보존하고 오류를 알린다. 에밀리아의 별도 저장 키는 유지한다.

이번 회랑 수정 전 소스·Git 백업: `/workspace/backups/Saibi-before-corridor-20261126T022045Z/`. 이전 취소선 수정 전 백업도 별도로 유지한다. `manifest.json`과 `RESTORE.md`를 함께 보존한다. 이 백업은 브라우저 localStorage를 포함하지 않는다. 배포 역시 기존 gh-pages 기록 위의 일반 커밋으로 되돌릴 수 있다.

## 검증

`npm test`는 61개 검증을 포함한다. 새 회랑의 단어·문 게이트, 반복 편집, 태양 1회 차감, 연출 도중 중복 거절, 0 생명력 복구, 구버전 저장 및 비교 버전 저장 분리를 검증한다. 부분 피복·명사 공유·여러 단어 억제·대안 해법·효과 되돌리기·저장 복원·거리/연출 중 거절·가까운 발판 복구·구버전 마이그레이션·단일 최종 확정과 기존 에밀리아 검증을 포함한다. `npm run build`로 TypeScript와 Vite 빌드를 검사한다.

실제 Chromium에서 마우스로 세 구역을 이동하고 취소선을 끌어 인물 소멸, 어둠 속 기억, 문 소멸과 동사만 억제하는 대안, 구속 해제, 저항, 새 신앙, 복원·재적용, 최종 귀환을 확인했다. 편집 중 저장 불변과 새로고침 복원도 확인했다. 브라우저 검증은 전체 미술 품질이나 모든 기기에서의 사용성을 보장하지 않는다.
