# 프롤로그 횡스크롤 심상던전

## 플레이 방식

PC 가로 화면을 우선한다. 좌우 방향키 또는 A/D로 걷고 Space로 낮게 점프한다. 숫자 키, 마우스 휠 또는 하단 단어 조각 클릭으로 손에 들 단어를 선택한다. 문장 가까이서 E를 누르거나 현장 안내 버튼을 클릭하면 조각을 끼우거나 문장을 조사한다. R은 뽑기/원상복구다. Escape로 멈춘다. 키보드 포커스가 무대를 벗어나거나 창이 비활성화되면 물리가 멈춘다.

일반 편집창이나 확정 버튼은 없다. 끼우는 동작에서 문장·지형·저장을 함께 변경한다. 단어 선택과 손에 들기는 저장 효과가 없다. 단어는 소모되지 않으며 다른 장소에서도 쓸 수 있다. 틀린 단어와 미수집 단어는 효과를 적용하지 않는다. 문장은 개별 오브젝트/규칙/옵션 ID로 변경하므로 전체 문자열 검색 치환을 하지 않는다.

## 세 구역

1. **배신의 회랑**: 입구의 대화 조각에서 놓친 키워드를 회수할 수 있다. E로 ‘절대로’를 뜯으면 벽이 사라지고 희미한 취소선이 남는다. 느낌표는 뒤집을 수 있다. ‘동료’를 선택해 믿음의 문장에 끼우면 밑줄 다리가 펼쳐진다. 건너편 인형의 기억을 듣고 다음 구역으로 이동한다.
2. **응답 없는 예배당**: ‘아니야’를 뜯고, 문에 ‘공적’을 끼운다. 봉인에는 세 차례 상호작용한다(편집 시도 → 종이 뒤집기 → 나레이터 도움). 이야기를 끝까지 들으면 봉인 뒤 통로가 열린다.
3. **이름 없는 제단**: 두 사고의 걸이를 바꾸면 인형 배치와 색이 바뀐다. 믿음의 문장에 ‘사도’ 등 수집한 관련 단어를 대면 저항과 나레이터 개입이 발생한다. 이후 단어 띠에 나타난 가려진 이름을 선택해 같은 문장에 끼운다. 이 상태는 저장되지만 최종 개종 결과는 아직 적용하지 않는다. R로 되돌릴 수 있다. 오른쪽 제단 앞에서 E로 통과할 때 기존 MindEvent 결과를 한 번 확정하고 폐허로 돌아온다.

현재 프롤로그에는 추격·시간 제한·정밀 점프 실패 페널티가 없다. 낙하는 해당 구역 입구에서 재개하며 단어와 편집을 보존한다. 이전 저장의 안정도 0은 복구 버튼으로 재개한다. 기존 에밀리아 던전의 적과 안정도 시스템은 변경하지 않는다.

## 데이터와 모듈 경계

`world.json`의 오브젝트 좌표는 횡스크롤 좌표다. 방은 폭 2800, 바닥 높이 620이며 카메라는 가로 방향을 따라간다. `sideScroll.json`에 발판과 조건부 다리, 상태별 벽, 직접 상호작용 슬롯이 있다.

```json
{
  "objectId": "trust_bridge",
  "ruleId": "bridge_rule",
  "mode": "word",
  "insert": "companion",
  "remove": "empty",
  "keywordId": "companion",
  "verb": "동료 끼우기",
  "restore": "동료 뽑기"
}
```

- `sideScroll.ts`: 데이터 참조/지형 검증, 활성 지형, 안전 체크포인트, 슬롯 옵션 계산. React·Phaser·Zustand에 의존하지 않는다.
- `store.touch`: 현재 방/거리/연출 중 여부/소유 단어 확인 후 기존 환경 action 또는 최종 신념 action을 호출한다.
- `SideScrollScene`: 같은 활성 지형 목록으로 실제 충돌체와 무대를 구성한다. 이동과 카메라, 종이 인형·실·활자 연출만 담당한다.
- `PrologueDungeon`: 단어 선택은 React 임시 상태, 실제 의미 변화는 store action이다. 비동기 import 취소 및 Game/리스너 해제 처리를 한다.

최종 `identity=placed`는 종이를 끼운 가역적 상태다. `editResult`는 제단 통과 전에는 null이다. 최종 전이는 `identity=rewritten`, 결과/플래그/이벤트 기록과 후속 대화를 함께 저장한다. 최종 문장은 데이터에 정의된 ‘나는 ■■■■■■■의 사도다.’이고 나머지 사명은 유지된다.

## 저장 호환

스키마 1을 유지하고 콘텐츠 버전을 `first-act-1`에서 `first-act-side-2`로 변경했다. 알려진 이전 저장만 마이그레이션한다. 기존 구역과 퍼즐 진행을 보존하고 탑다운 좌표는 그 방의 입구로 옮긴다. 숨겨진 이름을 끼운 채 새로고침해도 가역적인 상태로 복원되며, 마지막 제단을 통과해야 완료된다. 미지정 버전/손상 데이터는 보존한 채 오류를 알린다.

## 자동 검증과 직접 확인

자동 검증은 기존 45개와 신규 7개, 총 52개다. 신규 검증은 다음을 포함한다.

- 잘못된/미수집 단어 거절, 재사용, 삽입과 뽑기 저장 복원
- 세 구역 직접 조작부터 마지막 이름·캐릭터 전환까지 전체 흐름
- 멀리서 조작/연출 도중 입력 거절, 낙하 복구
- 구버전 저장 마이그레이션 및 별도 에밀리아 저장 보존
- 바닥 연결, 선택적 계단의 점프 가능 높이, 다리 없이 건널 수 없는 간격
- 복원된 벽 안이나 제거된 다리 위에서 안전한 좌표로 복구
- 이름을 끼운 뒤 이전 구역을 방문하고 돌아와도 최종 진행 가능

브라우저 도구 부재로 실제 화면/입력 검수는 별도로 필요하다. 직접 확인 순서:

1. 타이틀에서 새 공연 또는 기존 던전 저장 이어하기. 좌우 이동과 Space 점프, 카메라 추적 확인.
2. 틀린 단어를 다리에 넣어도 열리지 않는지 확인. ‘동료’ 삽입 → 다리 생성 → R로 뽑기 → 복구 확인.
3. 단어 삽입 후 새로고침. 문장/다리/소유 단어가 유지되는지 확인.
4. 나레이션과 일시정지, 창 전환 중 이동이 멈추는지 확인.
5. 예배당 봉인과 제단의 마지막 이름 진행. 이름 삽입 후 새로고침 → 뽑기 → 재삽입 → 제단 통과 확인.
6. 폐허 귀환 이후 이름 입력, 금발 인물로 역할 전환, 세루스와 기존 에밀리아 진입 확인.

로컬 실행:

```sh
npm ci
npm run dev -- --host 0.0.0.0
```

로컬 브라우저에서 Vite가 출력하는 주소를 연다. 원격 실행 환경에서는 단순 localhost 대신 환경의 포트 미리보기 주소 또는 배포된 게임 주소를 사용한다.

## 입력·회랑 진행 수정

- 스페이스/방향키를 React에서 미리 취소하던 처리를 제거했다. Phaser 키보드의 이벤트 대상을 포커스 가능한 게임 화면으로 지정해 게임 입력을 먼저 처리하고 페이지 스크롤을 차단한다. 메뉴/입력창의 키는 게임에 전달하지 않는다.
- 배신의 회랑에서 첫 퍼즐 이전의 높이 40 턱을 제거했다. 첫 문장까지 평지로 접근할 수 있다.
- 다리가 펼쳐지면 실제 충돌면의 높이에 밝은 밑줄과 문장을 표시한다. 캐릭터 SVG의 옷자락 끝을 이미지 원점으로 삼아 물리 발끝(`body.bottom`)에 맞춘다. 발을 지면 아래로 움직이던 상하 흔들림은 없앴다.
- 점프를 시작한 프레임에는 바닥 체크포인트를 기록하지 않아 저장 좌표 복원이 도약을 끊지 않도록 했다.
- `tests/stageInput.test.ts`에서 설치된 Phaser의 실제 KeyboardManager/Key를 호출해 Space·방향키 전달, 스크롤 차단, 키 해제, 메뉴 입력 분리, 리스너 해제를 확인한다. 이는 브라우저 실플레이를 대체하지 않는다. 회랑 평지·다리 연결·발끝 기준도 검사한다.

배포 후 게임 화면을 클릭하고 방향키 이동 → Space 점프 → 첫 문장 E → 동료를 다리에 삽입 → 다리 위 걷기 순서로 확인한다. 기존 저장은 그대로 이어갈 수 있다.

수정 후 전체 테스트 55개, TypeScript 검사와 Vite 빌드가 통과했다. 실제 브라우저 조작 검수는 도구 부재로 수행하지 못했다.
