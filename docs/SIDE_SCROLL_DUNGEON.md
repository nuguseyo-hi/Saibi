# 프롤로그 횡스크롤 심상던전 — 회랑 단어 삽입과 취소선

## 현재 플레이 방식

PC 가로 화면을 우선한다. 배신의 회랑에서는 이전 대화에서 얻은 단어를 빈칸으로 끌어 넣거나, 1–5로 단어를 선택하고 문장 가까이서 E로 넣는다. R은 단어 회수다. 대화 키워드 버튼을 누르지 않아도 해당 답변을 읽고 다음으로 넘어가면 키워드가 보관된다. 회랑에는 취소선과 독백 패널을 표시하지 않는다. 배경의 ‘나는 누구도 믿지 않아.’와 ‘그런데 왜?’가 내면을 전달한다.

**프롤로그는 신이 직접 편집을 돕는 구간이므로 편집 횟수가 무제한이다.** 본편의 편집 횟수·회복 방식은 아직 구현하지 않는다. 생명력은 별개이며 ‘태양의 신’을 회랑 다리 문장에 넣으면 1 감소한다. 연출 중 중복 입력은 차감하지 않는다. 0이 되면 회랑 입구에서 생명력 3으로 재시작하고 키워드·완료한 편집은 유지한다.

다음 조작 설명은 예배당·제단의 취소선에 해당한다. A/D 또는 좌우 방향키로 걷고 Space로 점프한다. 문장 가까이서 붉은 취소선 가운데를 끌면 위치가, 양 끝을 끌면 길이와 각도가 바뀐다. 단어 전체를 가리면 해당 명사나 동작이 억제된다. 일부만 가리면 황색 표시만 나타나며 효과는 없다. 하나의 긴 선으로 여러 단어를 억제할 수도 있다.

드래그 중에는 지형과 인물 반응을 미리 보여 주고 이동 물리를 멈춘다. 놓을 때 좌표·거리·범위를 검증해 자동 저장한다. 종이 바깥이나 너무 짧은 선은 거절하고 이전 상태로 복귀한다. R 또는 복원 버튼으로 취소선을 떼고 세계를 원상복구한다. 편집 취소·일시정지·창 비활성화는 초안을 폐기한다. 확정 전 초안은 저장하지 않는다.

키보드는 Q로 집기, 1 전체 / 2 첫 끝 / 3 둘째 끝, 방향키로 10px 이동(Shift 병용 1px), Enter로 놓기, Escape로 취소한다. E는 기억·문·제단을 조사한다. 편집 중이 아닐 때 Escape로 일시정지한다. 화면 바깥의 메뉴에 포커스가 있으면 이동하지 않는다.

## 세 구역과 관찰 결과

| 구역 | 문장과 조작 | 환경과 인물의 변화 |
| --- | --- | --- |
| 배신의 회랑 | 나는 (　)를 믿었다 / 동료를 향한 나의 믿음은 ____으로 돌아왔다 | ‘동료’로 해골 다리를 조립하고 ‘배신’으로 문자 문의 빈 부분을 잇는다. 태양의 신은 태양을 띄우고 생명력 1을 차감한 뒤 거대한 손이 끈다. 다른 단어는 돌아온다. 문을 열면 예배당의 빛과 전환 나레이션으로 이어진다. |
| 응답 없는 예배당 | 빛이 있는 곳에 길이 있으리 / 태양의 빛은 결코 거짓을 허락치 않으리 / 전능하신 그분께 기도하라 | 두 빛은 연결된다. 빛을 지우면 보호막과 원래 길이 사라지고 남은 책장 발판으로 기억의 어둠을 수집한다. 첫 빛에 어둠을 끼워 계단을 만든 뒤 높은 출구로 이동한다. 태양을 지우면 우주 형상과 나레이터 개입 후 취소선이 초기 위치·길이·각도로 돌아온다. |
| 이름 없는 제단 | 나는 태양의 신을 섬긴다 / 의심은 나를 붙잡는다 | ‘나’는 자아를 흐리게 하지만 개종을 완료하지 못한다. ‘붙잡는다’는 인형줄과 자세를 풀어도 신앙은 남긴다. 자아를 보존한 채 ‘태양의 신’ 또는 ‘섬긴다’를 지우면 저항·나레이터 개입 뒤 새 신앙이 들어선다. |

제단에서 화면 오른쪽 인물은 실제 변화 대상이다. 예배당은 인물·상태·독백 UI를 숨기고 기억을 배경 종이에 직접 표시한다. 소멸 시 투명도, 구속 시 기울어진 자세와 실, 신앙 변화 시 색과 붉은 실·눈, 반응 독백으로 결과를 보여 준다. 바뀐 단어에서 인물로 조각이 이동한다. 연출 감소 모드는 입자와 이동 연출을 줄이고 의미 변화는 유지한다. 봉인과 저항에는 거대한 손이 개입한다.

회랑에서는 입장 안내, 첫 빈칸 조사, 문자 문 완성, 문 열기 나레이션을 구분한다. 태양 연출 이후 단어는 반환되고 다리 문장은 비워진다. 예배당의 기존 봉인 단계는 어둠 수집·삽입·계단 통과로 대체한다. 제단의 새 신앙은 `identity=placed`라는 가역 상태다. R로 원래 신앙을 복구할 수 있으며, 오른쪽 최종 문턱에서 E를 눌러 무대가 접힌 뒤 한 번만 결과를 확정한다. 폐허 귀환·이름 입력·금발 인물 조작 인계·세루스 연결은 유지한다. 기존 에밀리아 던전은 변경하지 않는다.

다리 아래로 추락하면 구역에서 재개한다. 편집 또는 저장 복원으로 발밑 다리가 사라진 경우에는 가까운 안전한 가장자리로 이동시킨다. 해당 가장자리에서도 취소선을 복원할 수 있어 진행이 막히지 않는다.

## 예배당 상세 규칙

- 어둠은 첫 문장에만 삽입한다. 삽입 중 두 번째 빛은 계속 지워져 보호막이 돌아오지 않는다. 어둠을 먼저 뽑은 뒤 R로 빛을 복원한다.
- 길 또는 있으리를 지우면 계단이 성립하지 않는다. 거짓·허락치 않으리를 지우면 보호막만 풀리며 어둠 계단 없이는 높은 출구에 닿지 못한다.
- 전능하신은 광륜, 기도하라는 기도 파문 장식에 대응한다. 이 두 단어만으로는 통과할 수 없다.
- 태양은 매번 개입 연출을 발생시킨다. 연출이 끝나면 초기 취소선으로 돌아오며 수집·삽입·회랑·제단 진행을 초기화하지 않는다.
- 입구, 세 수집 발판과 출구 발판은 영구 지형이다. 상승 폭 50px, 수집 구간 간격 50–60px이며 점프 높이는 약 64.8px이다. 길이 사라질 때 안전한 발판에 재배치한다.
- `chapel.json`은 기억·계단·안내, `chapel.ts`는 검증과 저장 상태, `ChapelLayer.ts`는 무대 기억·우주 형상·손을 담당한다. 대사와 효과 확정은 기존 JSON 및 store 경계를 유지한다.

## 데이터와 모듈 경계

- `src/content/prologue/corridor.json` / `corridor.ts` / `CorridorLayer.ts`: 회랑의 정확한 문구·빈칸 좌표·기하 검증·해골 조립·배경 독백·문자 문·태양/손 연출. 삽입과 비용 확정은 store가 담당한다.
- `src/content/prologue/strikes.json`: 안정적인 단어 ID, 명사 참조/동사 역할, 글자 폭·위치, 종이 범위, 초기 취소선, 인물 독백, 안내 문구.
- `src/prologue/strikes.ts`: JSON 검증, 선분과 단어의 기하학적 피복, 명사 공유, 파생 환경, 구버전 결과를 취소선으로 변환. React·Phaser·Zustand에 의존하지 않는다.
- `src/prologue/StrikeLayer.ts`: 실제 마우스/키보드 편집, 초안, 부분 피복 강조, 연결된 단어의 취소선 표시와 리스너 정리. 단어 클릭으로 정답을 고르는 인터페이스는 사용하지 않는다.
- `src/prologue/SideScrollScene.ts`: 이동·충돌·카메라, 실제 지형 및 인물 연출. 의미 효과는 typed bridge로 전달한다.
- `src/prologue/store.ts`: 편집 가능 거리·진행·좌표 검사, 저장·복원·되돌리기, 저항과 단일 최종 확정.
- `src/prologue/PrologueDungeon.tsx`: 안내·반응·나레이션·일시정지. 편집 초안을 영구 진행에 직접 쓰지 않는다.
- `sideScroll.json` / `sideScroll.ts`: 바닥·충돌·게이트 및 안전 좌표. 이전 슬롯 정의는 알려진 데이터 호환용으로 남아 있지만 현재 퍼즐 화면에는 노출하지 않는다.

## 저장 호환과 복구

스키마 1, 콘텐츠 버전 `first-act-chapel-5`를 사용한다. `chapel={collected,inserted}`와 파생값 `chapelPath=light|broken|stairs`를 저장한다. 이전 콘텐츠의 예배당 진행은 새 퍼즐 입구에서 재개하며 대화·회랑·수집 키워드를 보존한다. 이미 제단에 도착했거나 프롤로그를 끝낸 저장은 어둠 삽입 완료로 변환하여 진행을 보존한다. `first-act-corridor-4`도 지원한다. `first-act-1`, `first-act-side-2`, `first-act-strike-3`의 알려진 퍼즐 결과를 새 회랑의 삽입 상태와 나머지 취소선 좌표로 변환하며 구역·이야기·개종 결과를 보존한다. 첫 변경 전 원본 저장은 덮어쓰지 않는다. 미지정 버전, 손상 좌표, 취소선과 환경이 불일치하는 저장은 보존하고 오류를 알린다. 에밀리아의 별도 저장 키는 유지한다.

이번 회랑 수정 전 소스·Git 백업: `/workspace/backups/Saibi-before-corridor-20261126T022045Z/`. 이전 취소선 수정 전 백업도 별도로 유지한다. `manifest.json`과 `RESTORE.md`를 함께 보존한다. 이 백업은 브라우저 localStorage를 포함하지 않는다. 배포 역시 기존 gh-pages 기록 위의 일반 커밋으로 되돌릴 수 있다.

## 검증

`npm test`는 67개 검증을 포함한다. 기존 에밀리아·프롤로그·회랑·제단 검증 외에 예배당의 연결된 빛, 수집 전 차단, 어둠 삽입·회수, 태양 연출 중 저장과 원위치 복귀, 손상 저장 보존, 구버전 변환 및 점프 궤적상 발판 도달 가능성을 검사한다. `npm run build -- --base=/Saibi/`로 TypeScript와 Vite 빌드를 검사한다.

이번 예배당 변경은 브라우저 도구가 없어 실제 화면·포인터 드래그·점프 감각을 검증하지 못했다. 자동 테스트는 상태 규칙과 기하 검증이며 실제 플레이 검증을 대신하지 않는다.

브라우저 확인 순서:

1. 회랑을 끝내 예배당에 진입한다. 두 빛 중 하나를 취소선으로 가리면 무대가 어두워지고 보호막이 사라지는지 확인한다.
2. A/D와 Space로 남아 있는 넓은 책장 발판 세 개를 건너, 기억 가까이에서 E 또는 어둠 클릭으로 수집한다.
3. 첫 문장 근처로 돌아와 어둠 토큰을 첫 빛으로 드래그하거나 E로 삽입한다. 어둠이 있는 곳에 길이 있으리로 바뀌고 계단이 생기는지 확인한다.
4. R로 단어를 뽑고 취소선을 복원한다. 수집한 어둠이 남아 있고 다시 삽입할 수 있어야 한다.
5. 태양을 지운 뒤 우주 형상·손·나레이터를 확인한다. 계속 듣기 후 선이 원래 위치·길이·각도로 돌아오고 수집 진행은 보존되어야 한다.
6. 어둠 삽입 뒤 새로고침해 계단과 결과가 유지되는지, 계단 위 문에서 E를 눌러 제단으로 이어지는지 확인한다.
