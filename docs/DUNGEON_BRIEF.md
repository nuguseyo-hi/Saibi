# 심상세계 던전 프로토타입 개발 기획서

## 0. 프로젝트 개요 및 작업 지침

현재 React + TypeScript + Vite 기반으로 개발 중인 웹 비주얼노벨 게임에 새로운 시스템을 추가하려고 합니다.

기존 게임의 세계관은 다음과 같습니다.

플레이어는 외신 니알라토텝의 사도를 자처하는 여행자입니다. 변방 마을 세루스에 도착하여 낮에는 마을을 조사하고, 밤에는 교회를 찾아온 사람들의 고해성사를 듣습니다.

캐릭터의 경계도가 일정 수준 이하로 낮아지면 니알라토텝의 권능으로 상대의 정신세계에 침투할 수 있습니다.

기존에는 정신 침투 후 바로 텍스트 사고 편집 화면으로 이동하도록 기획했지만, 이제 그 사이에 **2D 탐험형 심상세계 던전**을 추가하려고 합니다.

### 가장 중요한 개발 원칙

- 기존 프로젝트를 새로 만들거나 초기화하지 마세요.
- 기존 React 컴포넌트와 비주얼노벨 기능을 유지해 주세요.
- 기존 게임의 저장 데이터와 상태 관리 구조를 최대한 재사용해 주세요.
- 기존 사고 편집 시스템을 삭제하지 마세요.
- 먼저 프로젝트의 현재 구현 상태를 확인한 뒤 확장해 주세요.
- 문서와 실제 코드가 다르다면 현재 동작 중인 코드를 우선 분석해 주세요.

작업 전에 존재하는 경우 다음 파일을 읽어주세요.

- `AGENTS.md`
- `docs/GAME_DESIGN.md`
- `docs/TECH_STACK.md`
- `docs/IMPLEMENTATION_PLAN.md`

# 1. 이번 프로토타입의 목표

**하나의 심상세계 던전을 입장부터 탈출까지 실제로 플레이할 수 있도록 구현합니다.**

이번 프로토타입은 다음 기능을 검증하기 위한 것입니다.

1. 2D 던전에서 플레이어 캐릭터 이동
2. 초현실적인 콜라주 배경 표현
3. 공격하는 문자형 적
4. 적과의 충돌 및 회피
5. 주변 사물과 문장 조사
6. 기억의 파편 수집
7. 문장을 수정하는 환경 퍼즐
8. 잠긴 구역 해금
9. 던전 최심부 진입
10. 핵심 사고 편집 시스템 연결
11. 게임 결과 반영 및 고해성사 복귀

최초 프로토타입의 목표 플레이 시간은 약 5~10분입니다.

복잡한 전투, 여러 던전, 캐릭터 육성, 랜덤 맵 생성 등은 이번 단계에서 구현하지 않습니다.

# 2. 기술 스택

현재의 React + TypeScript 프로젝트를 유지합니다.

심상세계 던전의 2D 탐험 부분은 Phaser를 사용해 구현합니다.

기술별 역할:

**React**
- 기존 비주얼노벨
- 고해성사
- 대화 및 선택지
- 던전 바깥의 UI
- 사고 편집 메뉴
- 결과 화면

**Phaser**
- 2D 던전 화면
- 플레이어 이동
- 카메라 이동
- 충돌 판정
- 문자형 적의 이동
- 공격 및 피격 판정
- 맵 전환
- 던전 내부 오브젝트

**Zustand 또는 기존 상태 관리 도구**
- 캐릭터 상태
- 던전 진입 조건
- 던전 진행 상태
- 기억 파편 획득 여부
- 퍼즐 해결 여부
- 확정된 편집 결과

**JSON**
- 던전 데이터
- 적 데이터
- 조사 가능 오브젝트
- 문장 퍼즐
- 기억 파편
- 이벤트 및 분기 조건

현재 설치된 패키지와 버전을 먼저 확인하고 호환 가능한 Phaser 버전을 선택해 주세요.

공식 React + Phaser + TypeScript 예제를 통합 구조의 참고 자료로 사용할 수 있으나, 기존 프로젝트 전체를 해당 템플릿으로 교체하지는 마세요.

# 3. 던전의 콘셉트

## 3.1 심상세계

심상세계는 각 캐릭터의 기억, 감정, 무의식적 이미지, 가치관과 내면의 서사가 공간으로 구현된 장소입니다.

현실적인 던전이 아니라 초현실적이고 비논리적인 세계입니다.

각 캐릭터의 심상세계는 서로 다른 테마와 구조를 가집니다.

이번 프로토타입은 '종소리를 들은 소녀 에밀리아'의 정신세계를 제작합니다.

## 3.2 시각적 콘셉트

비주얼은 다음 키워드를 중심으로 합니다.

- 초현실주의
- 컷아웃 애니메이션
- 아날로그 종이 콜라주
- 낡은 종이와 문서
- 흑백 판화
- 서로 다른 화풍의 이미지 조합
- 손으로 오려 붙인 듯한 오브젝트
- 움직이는 문자와 문장
- 불가능한 원근법
- 고딕 판타지
- 코스믹 호러

화면의 모든 물체가 동일한 화풍일 필요는 없습니다.

배경은 낡은 책의 삽화처럼 표현되고, 일부 오브젝트는 종이 인형처럼 움직이며, 글자들은 살아 있는 생물처럼 행동할 수 있습니다.

애니메이션 《마법소녀 마도카☆마기카》의 마녀 결계처럼 이질적인 이미지들이 조합된 공간을 시각적인 참고 방향으로 삼되, 기존 작품의 캐릭터·문양·배경·애니메이션·이미지를 직접 복제하지 않고 독창적인 비주얼을 제작합니다.

### 프로토타입의 그래픽 구현

실제 아트 리소스가 아직 없으므로 초기에는 다음 요소를 사용합니다.

- 단색 및 그라데이션 배경
- 반투명 종이 텍스처
- 기하학적 오브젝트
- CSS 또는 Phaser에서 생성한 도형
- 움직이는 텍스트
- 임시 플레이어 캐릭터
- 간단한 페이드 및 흔들림 애니메이션

완성된 이미지가 없어도 던전을 플레이할 수 있어야 합니다.

향후 PNG 및 WebP 이미지로 교체할 수 있도록 배경과 장식 오브젝트를 분리해 주세요.

# 4. 게임 조작 방식

2D 탑다운 시점으로 구현합니다.

플레이어는 던전 안에서 자유롭게 이동할 수 있습니다.

### 기본 조작

| 입력 | 기능 |
|---|---|
| WASD | 캐릭터 이동 |
| 방향키 | 캐릭터 이동 |
| E | 근처 오브젝트 조사 |
| 마우스 클릭 | 퍼즐 선택 및 UI 조작 |
| ESC | 열린 퍼즐 닫기 / 일시정지 |

추가 요구사항:

- 대각선 이동 속도 정규화
- 벽과 장애물의 충돌 판정
- 장애물을 통과할 수 없도록 처리
- 화면 밖으로 이동할 수 없도록 제한
- 조사가 가능한 오브젝트에 접근하면 상호작용 표시
- 게임 내 텍스트 퍼즐을 실행하는 동안 이동 일시정지
- 브라우저 창 크기에 따른 화면 조정

초기 화면 비율은 16:9를 기준으로 합니다.

기준 내부 해상도는 1280×720을 제안하지만, 기존 UI 설계와 충돌한다면 조정해도 됩니다.

# 5. 프로토타입 던전: 에밀리아의 심상세계

## 던전 이름

**제1심층 — 존재하지 않는 종소리**

### 스토리 배경

에밀리아는 어느 날 밤 교회의 종소리를 들었습니다.

하지만 그 교회에는 오래전부터 종이 존재하지 않았습니다.

에밀리아는 그날 밤의 사건에 관한 불완전한 기억을 가지고 있으며, 그 기억은 여러 장면으로 파편화되어 있습니다.

플레이어는 에밀리아의 정신세계에 침투하여 기억의 파편을 수집하고, 최심부에 존재하는 종소리에 관한 핵심 사고에 접근해야 합니다.

## 5.1 던전 구조

프로토타입에서는 네 개의 구역을 구현합니다.

### ROOM 01 — 기억의 입구

기본적인 조작과 분위기를 소개하는 공간입니다.

- 플레이어 캐릭터 등장
- 이동 및 충돌 테스트
- 배경에 떠다니는 문장
- 조사할 수 있는 오브젝트 한 개
- 다음 방으로 이동하는 문

오브젝트를 조사하면 에밀리아의 기억에 관한 짧은 문장이 나타납니다.

### ROOM 02 — 부정의 복도

문자형 적이 등장하는 공간입니다.

- 움직이는 문자형 적 2종
- 피격 판정
- 회피
- 기억 파편 한 개
- 문장 수정으로 열리는 문

플레이어는 적을 피하면서 기억 파편을 획득하고 환경 퍼즐을 해결해야 합니다.

### ROOM 03 — 찢어진 편지의 방

기억과 문장을 조사하는 공간입니다.

- 조사 가능한 편지
- 문장으로 구성된 환경 퍼즐
- 기억 파편 두 개
- 기억 파편을 모아야 열리는 문

이 방에서는 기존 텍스트 편집 시스템을 활용한 짧은 퍼즐을 구현합니다.

### ROOM 04 — 종소리의 중심

최종 사고 편집 공간입니다.

- 거대한 종을 상징하는 오브젝트
- 핵심 기억을 표현한 문장
- 기억 파편 조건 확인
- 핵심 사고 편집 UI
- 편집 확정
- 던전 종료 및 고해성사 복귀

이번 프로토타입에서는 각 방을 고정된 구조로 구현합니다.

랜덤 생성은 사용하지 않습니다.

# 6. 문자형 적 시스템

심상세계에서는 특정 문자나 문장이 살아 움직이며 플레이어를 공격합니다.

적은 현실적인 생물이나 무기를 사용하지 않습니다.

문자 자체가 움직이고, 충돌하고, 플레이어를 방해하는 방식으로 구현합니다.

## 6.1 적 A: '싫어'

### 특징

부정과 거부를 상징하는 문자입니다.

### 행동

- 평소에는 정해진 범위에서 배회
- 플레이어가 일정 거리 안에 들어오면 접근
- 플레이어와 접촉하면 피격 처리
- 이후 잠시 뒤로 물러나거나 배회 상태로 복귀

### 비주얼

- 붉은색 또는 검붉은 텍스트
- 글자가 미세하게 흔들림
- 이동할 때 글자의 위치가 불규칙하게 변화
- 플레이어를 발견하면 글자가 커짐

## 6.2 적 B: '안 돼'

### 특징

행동을 제한하고 통로를 막는 문자입니다.

### 행동

- 특정 통로 주변을 순찰
- 플레이어가 접근하면 짧게 돌진
- 돌진 전 텍스트가 커지고 깜빡이는 예고 동작 표시
- 돌진이 끝나면 잠시 정지

### 비주얼

- 검은색 문자와 붉은 잔상
- 돌진할 때 글자가 여러 겹으로 겹침
- 공격 전 문자가 늘어나는 효과

## 6.3 적과의 충돌

초기에는 체력 대신 '침투 안정도'라는 자원을 사용합니다.

기본 침투 안정도: 3

- 적에게 접촉하면 안정도 1 감소
- 피격 후 약 1초간 무적
- 안정도가 0이 되면 침투 실패
- 침투 실패 시 고해성사 화면으로 복귀

침투 실패 시 기존 캐릭터의 경계도가 상승하도록 합니다.

초기 테스트에서는 경계도 +10을 제안합니다.

값은 데이터에서 조정할 수 있어야 합니다.

**이번 프로토타입에서는 적을 직접 공격해 제거하는 전투 시스템은 구현하지 않습니다.**

적을 피하고, 지형을 활용하고, 퍼즐을 해결해 진행하는 것이 기본입니다.

# 7. 환경 사고 편집 퍼즐

던전 내부에는 세계의 규칙을 설명하는 문장들이 존재합니다.

일부 문장은 니알라토텝의 권능으로 수정할 수 있습니다.

문장을 수정하면 실제 던전의 오브젝트와 환경이 변화합니다.

## 퍼즐 01 — 닫힌 문

플레이어의 앞에 잠긴 문이 존재합니다.

문에는 다음 문장이 적혀 있습니다.

"이 문은 절대로 열리지 않는다."

플레이어는 '절대로'라는 단어를 클릭할 수 있습니다.

변경 가능한 단어:

- 절대로
- 언젠가는
- 이미

### 결과

**절대로**
- 문이 닫힌 상태로 유지됩니다.

**언젠가는**
- 일정 시간이 지나면 문이 열립니다.

**이미**
- 문이 즉시 열립니다.

문장이 변경되면 실제 문 오브젝트의 상태가 변화해야 합니다.

이번 단계에서는 이 퍼즐 한 개로 '텍스트 편집이 던전 환경에 영향을 미친다'는 메카닉을 검증합니다.

# 8. 기억 파편 시스템

던전 곳곳에 캐릭터의 기억이 파편 형태로 존재합니다.

플레이어는 오브젝트를 조사하거나 퍼즐을 해결해 기억 파편을 획득합니다.

### 기억 파편 예시

**파편 A — 종소리**

"그날 밤 나는 분명 종소리를 들었다."

**파편 B — 편지**

"소리가 들린 뒤 오래된 편지 한 장을 발견했다."

**파편 C — 종탑**

"그런데 그 교회에는 종이 없었다."

### 게임 기능

- 기억 파편은 조사 가능한 오브젝트로 표현
- 획득 시 짧은 텍스트 연출
- 화면에서 획득한 파편 개수 확인 가능
- 획득한 기억을 목록에서 다시 읽을 수 있음
- 이미 획득한 파편은 중복 획득 불가능
- 파편 획득 상태 저장

이번 테스트에서는 기억 파편 세 개를 모두 획득해야 마지막 핵심 기억에 접근할 수 있도록 합니다.

# 9. 핵심 사고 편집 시스템

던전의 마지막 공간에는 캐릭터의 핵심 사고가 존재합니다.

이 공간은 일반적인 퍼즐 방이 아니라 캐릭터의 심층 기억을 상징하는 공간입니다.

중앙에는 거대한 종 오브젝트가 떠 있습니다.

플레이어가 접근해 상호작용하면 핵심 사고 편집 UI가 열립니다.

### 기본 텍스트

"그날 밤 나는 존재하지 않는 종소리를 들었다."

"그것은 단순한 우연이었을 것이다."

"그러나 누군가는 나를 부르고 있었다."

### 편집 가능한 부분

두 번째 문장의 '우연'을 변경할 수 있습니다.

선택지:

- 우연
- 계시
- 착각

이번 프로토타입에서는 단어 하나의 치환 결과를 통해 서로 다른 분기를 발생시킵니다.

### 결과 A — 계시

에밀리아의 기억 속에서 종소리의 의미가 달라집니다.

던전의 종 오브젝트가 반응하며 특수한 연출이 발생합니다.

니알라토텝과 관련된 후속 스토리 플래그가 설정됩니다.

### 결과 B — 착각

종소리에 관한 기억이 불확실한 것으로 재구성됩니다.

던전의 종 오브젝트가 흐릿해집니다.

에밀리아의 후속 대사가 달라집니다.

### 결과 C — 우연 유지

기존 기억을 수정하지 않습니다.

핵심 사고가 유지된 상태로 던전을 종료합니다.

### 강한 암시 연출

사고 편집을 확정할 때 외신의 권능이 발동하는 초자연적인 연출을 추가합니다.

화면 중앙에 검게 가려진 문장과 신의 상징이 나타나는 방식입니다.

구체적인 연출과 대사는 추후 시나리오 데이터에서 교체할 수 있게 합니다.

이번 프로토타입에서는 복잡한 신앙도 계산을 구현하지 않고, 결과 플래그만 저장합니다.

# 10. 정신 침투 진입 조건

기존 고해성사 시스템과 연결합니다.

캐릭터의 경계도가 20 이하일 때 정신 침투가 가능하다는 기존 규칙을 유지합니다.

진입 흐름:

1. 고해성사 진행
2. 정신 침투 조건 검사
3. 조건 충족 시 정신 침투 선택지 활성화
4. 플레이어가 정신 침투 선택
5. 화면 전환 연출
6. 심상세계 던전 시작

조건이 충족되지 않으면 진입할 수 없습니다.

다만 개발과 테스트를 위해 개발 모드에서는 조건을 무시하고 던전에 직접 입장할 수 있는 기능을 추가해 주세요.

현재 프로젝트에 경계도 시스템이 존재하지 않는다면 임시 테스트값을 사용할 수 있도록 해 주세요.

# 11. 던전 실패 및 복귀

던전에서는 두 가지 종료 방식이 존재합니다.

## A. 정상 종료

- 핵심 사고 편집을 확정함
- 퍼즐 결과 저장
- 던전 종료
- 기존 고해성사 화면 복귀
- 편집 결과에 따른 후속 대화 진행

## B. 침투 실패

- 침투 안정도가 0이 됨
- 심상세계가 플레이어를 배척하는 연출 발생
- 던전 종료
- 기존 고해성사 화면 복귀
- 캐릭터 경계도 상승
- 해당 밤의 침투 기회 소모

정확한 횟수와 실패 페널티는 추후 데이터로 변경할 수 있게 설계합니다.

프로토타입에서는 실패해도 다음 날 다시 도전할 수 있도록 하며, 영구적으로 진행이 막히지 않게 해 주세요.

# 12. React와 Phaser 연결

기존 게임 전체를 Phaser로 교체하지 않습니다.

심상세계 던전에서만 Phaser가 실행됩니다.

### 화면 전환

React 비주얼노벨 화면
→ 정신 침투 시작
→ Phaser 던전 활성화
→ 던전 종료 이벤트 발생
→ Phaser 정리
→ React 비주얼노벨 화면 복귀

### 구현 요구사항

- Phaser Game 인스턴스를 중복 생성하지 않도록 관리
- React 컴포넌트 언마운트 시 Phaser 리소스 정리
- React 개발 모드에서도 중복 Canvas가 생성되지 않도록 처리
- Phaser와 React 사이에 명확한 이벤트 전달 구조 사용
- 적 이동 같은 매 프레임 상태를 Zustand에 저장하지 않음
- 캐릭터 상태, 파편 획득, 결과 확정 등 의미 있는 이벤트만 공유
- 장면 전환 후 이벤트 리스너가 중복 등록되지 않도록 처리
- 게임 재진입 시 이전 던전의 적과 충돌 판정이 남아 있지 않도록 처리

Phaser 화면 위에 표시되는 퍼즐 메뉴와 대화 UI는 React로 구현해도 됩니다.

상호작용 중에는 Phaser의 플레이어 이동과 적 행동을 일시정지하도록 합니다.
