# 검은 기도 · VESPERS

> 최신 변경: 프롤로그의 세 구역은 횡스크롤과 현장 단어 삽입·뽑기를 사용합니다. 편집창을 여는 이전 프롤로그 설명은 대체되었습니다. 상세 구현·검증·조작은 [횡스크롤 구현 문서](docs/SIDE_SCROLL_DUNGEON.md)를 참고하세요. 기존 에밀리아 테스트는 유지됩니다.

## 새 프롤로그 — 최초의 사도

기본 시작 화면은 인형극 프롤로그입니다. 태양신의 금발 이단심문관이 정체성 편집으로 최초의 사도가 되고, 이름을 지은 뒤 그 인물로 제1장 세루스에 도착합니다. 나레이터의 정체는 프롤로그 화면에 명시하지 않습니다.

**막을 올리다 → 인형극 → 폐허 → 세 질문/키워드 → 인물 클릭 → 배신의 회랑 → 예배당 → 제단 → 이름 입력 → 세루스**.

던전 조작은 WASD/방향키·E·Escape입니다. 첫 구역의 접힌 대화에서 놓친 키워드를 모두 복구할 수 있습니다. 안정도가0이 되어도 해당 구역에서 재시도할 수 있습니다. ‘연출 약하게’로 글리치·움직임을 줄입니다.

자세한 퍼즐 확인 순서와 파일 목록은 [프롤로그 구현 계약](docs/PROLOGUE_IMPLEMENTATION.md)에 있습니다. 타이틀의 ‘기존 에밀리아 테스트 이어하기’는 아래 기존 게임을 엽니다. 프롤로그 저장 키는 `saibi.prologue.v1`이며 기존 에밀리아 저장을 덮어쓰지 않습니다. 새 공연은 프롤로그만 초기화합니다.

자동 테스트는 현재 45개입니다. 브라우저 실조작 검수는 미수행입니다. 세루스는 세 장소 조사와 기존 교회 테스트로 이어지는 최소 화면이며, 완성된 본편은 아닙니다.

## 기존 에밀리아 테스트 안내

React + TypeScript + Vite 비주얼노벨과 Phaser 심상던전 프로토타입입니다. 에밀리아의 종소리 기억을 탐험하는 네 방을 추가했습니다. 심상던전 전체는 생성한 종이·판화·천 콜라주 배경과 투명 인형/오브젝트를 사용합니다. 한글 명조 폰트도 로컬로 포함합니다.

플레이: https://vespers-black-prayer-7k2m.reflectivecanopy2.chatgpt.site

## 로컬 실행

Node.js 22.18 이상(권장 24 LTS), npm 환경에서 실행합니다.

```sh
npm ci
npm run dev
```

터미널의 Local 주소(기본 http://localhost:5173)를 같은 컴퓨터의 브라우저에서 엽니다. 원격 작업 환경의 localhost는 사용자 PC의 localhost와 다릅니다. 설치 없이 하려면 위 배포 주소를 사용하세요. 개발 서버 타이틀의 **DEV · 심상던전 직접 입장**은 저장 진행을 초기화하고 입구로 이동합니다. 실제 배포 빌드에는 이 버튼이 없습니다.

```sh
npm test
npm run typecheck
npm run build
npm run preview
```

preview 기본 주소는 http://localhost:4173 입니다. 포트가 사용 중이면 터미널의 실제 주소를 따릅니다. 개발·preview·배포 세이브는 origin이 달라 공유되지 않습니다.

## 플레이

새 게임 → 대화·선택 → 고해성사의 종소리 기억 → 정신 침투 → 네 방 탐험 → 세 파편 → 최심부 사고 편집 → 결과 연출 → 고해성사 복귀.

- 대화: 클릭 또는 Enter/Space. 선택지는 마우스 또는 키보드로 선택합니다.
- 던전: WASD/방향키 이동, E 조사/문 통과, Escape 일시정지·퍼즐 닫기. 이동하지 않으면 던전 화면을 클릭해 포커스를 주세요.
- 상단 기억 파편 버튼으로 모은 단서를 다시 읽습니다. 조사·퍼즐·일시정지 중 적과 플레이어는 멈춥니다.
- 부정의 복도: 파편을 조사하고 문장 퍼즐에서 **이미**를 확정하면 즉시 열립니다. **언젠가는**은 4초 뒤, **절대로**는 닫힘입니다.
- 편지의 방: 첫 편지 파편을 모으고 문장 퍼즐을 **이어진다**로 확정하면 나머지 파편에 접근합니다. 총 세 파편이 있어야 종소리의 중심에 진입합니다.
- 최심부 종에서 우연·계시·착각을 선택하고 확정합니다. 취소하면 던전으로 돌아가며 미확정 선택은 반영되지 않습니다.
- 안정도3, 접촉 피해1, 피격 후1초 무적. 실패 시 경계도+10, 밤당2회 진입. 고해성사의 **다음 밤에 다시 만나기**로 재도전할 수 있습니다.
- 실패/중단에도 파편·확정 퍼즐은 남습니다. 다시 들어가면 입구에서 시작합니다.
- 새 게임은 화면 안의 확인 버튼으로 저장을 교체합니다. 타이틀의 이어서 플레이는 마지막 체크포인트로 돌아갑니다.

## 브라우저 확인 항목

1. 기존 타이틀·스탠딩·대화·선택·로그가 유지되고 고해성사에서 던전으로 들어가는지 확인합니다.
2. WASD/방향키 대각선 속도, 벽·경계 충돌, E 표시, 카메라와 네 방 페이드를 확인합니다.
3. '싫어'의 추적과 '안 돼'의 확대·깜빡임 후 돌진을 피합니다. 연속 접촉이 즉시 안정도0을 만들지 않아야 합니다.
4. 퍼즐을 열면 이동·적이 정지하는지, 취소하면 문이 그대로인지, 위 세 문 옵션이 실제 문 상태를 바꾸는지 확인합니다.
5. 세 파편을 모으기 전 마지막 문이 잠기는지, 중복 조사가 파편 개수를 늘리지 않는지 확인합니다.
6. 우연/계시/착각을 각각 새 게임 또는 DEV 진입에서 확정해 결과 연출과 후속 대사를 비교합니다.
7. 파편 획득·퍼즐 확정·핵심 편집 도중·결과 확정 직후 각각 새로고침합니다. 확정 내용은 유지되고 미확정 초안만 초기화되어야 합니다.
8. 두 번 실패한 뒤 진입 제한과 다음 밤 재도전을 확인합니다. Escape 중단 후 재진입도 확인합니다.
9. 던전 진입/종 편집 취소/타이틀 복귀를 반복합니다. 개발자 도구에서 던전 중 `.phaser-host canvas`는 하나, 다른 화면에서는 0개여야 합니다. Console 오류가 없어야 합니다.
10. 1280×720·1920×1080과 작은 창에서 UI·스크롤·포커스를 확인합니다. PC 키보드가 필요하며 터치 이동은 미구현입니다.

## 저장과 검증

localStorage 단일 슬롯 `nyarlathotep-vn.save.v1`, 구조 버전2, 콘텐츠 `dungeon-1`. 이전 버전1/`confession-1` 저장은 기존 ID·기록·결과를 보존하며 이관합니다. 표시명은 에밀리아지만 호환성을 위해 내부 캐릭터 ID는 `elin`입니다. 손상/미지원 저장은 조용히 덮어쓰지 않습니다. 저장 실패는 안내와 재시도를 제공합니다. 다중 탭 저장 병합은 지원하지 않습니다.

34개 테스트: 기존 25개 회귀 + 네 방의 접근 가능한 경로, 문 세 옵션과 지연, 파편·잠금, 세 핵심 결과/취소/중복/복원, 실패/무적/재도전, 저장 이관. TypeScript 검사·Vite 빌드도 실행합니다. 실제 브라우저 조작 도구가 없어 화면·키보드·Canvas 수·실제 새로고침은 수동 확인이 필요합니다. 테스트의 store 복원과 실제 브라우저 검수를 구분합니다.

Phaser 엔진 청크는 지연 로딩되지만 크기가 커 첫 던전 진입에 다운로드 시간이 걸릴 수 있습니다. 실제 음원 없이 사운드 이벤트 훅만 제공합니다. 5~10분 플레이 시간은 목표이며 실측하지 않았습니다.
