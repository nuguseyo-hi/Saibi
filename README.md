# 검은 기도 · VESPERS

React + TypeScript + Vite 기반 고딕 판타지 비주얼노벨 초기 프로토타입입니다. 제목, 엘린, 대사와 두 결말은 기능 검증용 임시 콘텐츠입니다.

## 실행

Node.js 22.18 이상(권장 24 LTS), npm이 필요합니다. 프로젝트 폴더에서 실행하세요.

```sh
npm ci
npm run dev
```

터미널에 출력되는 Local URL(기본 `http://localhost:5173`)을 같은 컴퓨터의 브라우저에서 엽니다. 포트가 사용 중이면 실제 출력된 주소를 사용하세요. 원격 작업 환경의 localhost는 사용자 PC의 localhost와 다릅니다. 원격 실행에서는 해당 환경의 포트 미리보기 기능이 필요합니다.

```sh
npm test
npm run build
npm run preview
```

`build`는 TypeScript 검사 후 `dist/`를 생성합니다. `preview`는 빌드 결과를 서비스하며 기본 포트는 4173입니다. `npm run typecheck`로 타입 검사만 실행할 수 있습니다.

## 구현 범위

- 타이틀 → 게임 시작 → 교회 대화 → 두 선택지 → 서로 다른 후속 대사·마무리 → 타이틀.
- 직접 만든 로컬 SVG 교회 배경과 캐릭터 스탠딩 플레이스홀더.
- 반투명 하단 대화창, 클릭 또는 Enter/Space 진행, 키보드로 선택지 조작.
- JSON 시나리오, 런타임 구조·ID 참조 검증, Zustand 진행 상태, 대화 기록.
- PC 가로 화면 우선, 작은 창에서 대사와 선택지가 줄바꿈되는 레이아웃.

이번 단계에는 고해성사 전용 기능, 사고 편집, 캐릭터 수치 변화, 저장·이어하기가 없습니다. 새로고침하면 타이틀부터 시작합니다. 다음 개발 단계에서 저장 계약과 수치 정책을 확정한 뒤 도입합니다.

## 브라우저 확인

1. 타이틀에서 `게임 시작`을 누릅니다.
2. 교회 배경과 첫 서술을 확인하고, 대화창 또는 `다음`을 누릅니다.
3. 엘린의 스탠딩이 나타나는지 확인합니다. Enter/Space도 사용할 수 있습니다. 버튼에 포커스가 있다면 그 버튼이 작동합니다.
4. 선택지 노드에서 대화창을 클릭해도 선택이 건너뛰어지지 않는지 확인합니다.
5. 첫 선택지를 누르면 `작은 안식`, 두 번째를 누르면 `문 너머의 목소리`로 이어집니다. 각 경로는 타이틀에서 새 게임으로 시작해 따로 확인합니다.
6. `대화 기록`을 열어 당시 대사와 선택을 확인하고 닫기/Escape로 복귀합니다.
7. 1280×720, 1920×1080 및 좁은 창에서 버튼과 대사가 보이는지 확인합니다.
8. 개발자 도구 Console에 오류가 없고 Network에서 두 SVG가 정상 로드되는지 확인합니다.

## 콘텐츠 수정

`src/content/scenarios/intro.json`에서 대사와 선택지를 관리합니다. 캐릭터 정의도 현재는 이 JSON에 함께 있습니다. 향후 캐릭터 수가 늘면 manifest와 캐릭터 파일로 분리할 수 있습니다.

- `startNodeId`는 시작 노드 ID입니다.
- `speaker`는 캐릭터 ID, `narrator`, `player` 중 하나입니다.
- `characterId`가 있으면 해당 스탠딩을 표시합니다.
- 각 노드에는 `next`, `choices`, `ending` 중 하나만 사용합니다.
- 선택지는 `id`, `text`, `next`로 구성하며 `next`는 실제 노드 ID를 가리켜야 합니다.
- 종료 노드의 `ending`은 임시 마무리 제목입니다. 정식 엔딩 시스템은 아닙니다.

구조: `components/`는 표시, `domain/scenario.ts`는 데이터 검증·전이, `store/gameStore.ts`는 실행 상태, `content/`는 콘텐츠입니다. 실행 중 상태로 JSON 원본을 변경하지 않습니다.

## 검증 범위

`npm test`는 JSON 유효성, 잘못된 참조·ID·화자, 두 분기 완주, 선택지 건너뛰기 방지, 이전 노드 입력 재사용 방지, 새 게임 초기화를 확인합니다. 자동 테스트는 실제 브라우저 렌더링 검수를 대신하지 않습니다.
