# 검은 기도 · VESPERS

React + TypeScript + Vite 기반 고딕 판타지 비주얼노벨. 현재 고해성사와 사고 편집 테스트 버전입니다. 제목·엘린·대사는 임시 콘텐츠이며 실제 일러스트 대신 로컬 SVG를 사용합니다.

플레이 주소: https://vespers-black-prayer-7k2m.reflectivecanopy2.chatgpt.site

배포 소스 작업 폴더: `/workspace/sites/vespers-play`. `/workspace` 루트에 남은 초기 버전과 혼동하지 마세요. 사이트 ID와 정적 빌드 경로는 `.openai/hosting.json`에서 관리합니다.

## 로컬 실행

Node.js 22.18 이상(권장 24 LTS), npm 환경에서 프로젝트 폴더로 이동합니다.

```sh
npm ci
npm run dev
```

터미널의 Local URL(기본 http://localhost:5173)을 같은 컴퓨터의 브라우저에서 엽니다. 원격 환경의 localhost는 사용자 PC의 localhost와 다릅니다. 설치 없이 플레이하려면 위 배포 주소를 이용하세요.

```sh
npm test
npm run typecheck
npm run build
npm run preview
```

build는 타입 검사 후 `dist/`를 생성합니다. preview의 기본 포트는 4173입니다. 포트가 바뀌면 터미널에 표시된 주소를 사용합니다. localStorage는 origin 단위이므로 개발 서버·preview·배포 사이트 사이에 세이브가 공유되지 않습니다.

## 플레이 흐름

타이틀 → 게임 시작 → 방문자와 대화 → 고해성사 선택 → 종소리 기억 → 정신 침투 → 단어 치환/문장 삭제 → 확정 → 결과별 후속 대화 → 고해성사 완료.

- 일반 대화는 대화창 클릭, 다음 버튼, Enter/Space로 진행합니다. 선택지가 있을 때는 선택해야 합니다.
- `우연이었`을 클릭하면 우연·계시·착각을 선택할 수 있습니다. 문장에 맞는 활용형까지 JSON에 정의되어 있습니다.
- `그 종소리를 다시 듣는 것이 두렵다.`를 클릭하고 문장 삭제를 선택하면 취소선 흔적이 남습니다. 문장 유지로 되돌릴 수 있습니다.
- 치환과 삭제를 함께 할 수 있으며, 확정 전에는 게임의 기억·플래그가 바뀌지 않습니다.
- `모두 원문으로`는 초안을 초기화합니다. `편집 취소`는 효과 없이 진입 직전 고해성사로 복귀합니다. 다시 정신 침투할 수 있습니다.
- 원문 그대로 확정하는 것도 유효한 결과입니다. `편집 확정` 후 즉시 후속 대화로 돌아갑니다.
- `기억 기록`에서 확정 문장과 원문을 비교합니다. 삭제된 문장은 편집 후 기억에서 빠지고 원문 비교에서만 보입니다.
- 진행과 확정 결과는 자동 저장됩니다. 새로고침하면 마지막 저장 화면이 복원됩니다. 편집 중 새로고침하거나 타이틀로 나가면 미확정 초안만 폐기됩니다.
- 타이틀의 `이어서 플레이`로 체크포인트에 복귀합니다. `새 게임`은 확인 후 기존 저장을 교체합니다.

## 브라우저에서 직접 확인할 항목

1. 배포 페이지를 새로고침하고 새 게임을 시작합니다. 기존 배경·스탠딩·선택지·대화 기록이 유지되는지 확인합니다.
2. 고해성사에서 종소리 대화까지 진행한 뒤 `정신 침투`를 누릅니다. 화면 페이드와 편집 대상 강조·hover·키보드 포커스를 확인합니다.
3. 우연→계시로 바꾸면 `계시였을 것이다`가 되고, 아래 문장에 있는 다른 `우연`은 그대로인지 확인합니다.
4. 삭제할 문장 선택 → 문장 삭제 → 흐릿한 취소선 → 문장 유지 순으로 확인합니다. 미리보기에서도 결과를 확인합니다.
5. 치환·삭제 후 `편집 취소`를 눌러 복귀합니다. 다시 진입하면 원문이며 기억 기록에 새 결과가 없어야 합니다.
6. 아래 여섯 조합을 각각 새 게임에서 확정합니다. 첫 후속 대사와 다음 대사를 확인합니다.
7. 확정 직후 새로고침하고 `기억 기록`을 엽니다. 후속 대사 위치, 편집 후 문장, 결과 개수가 유지되어야 합니다.
8. 확정 버튼을 빠르게 두 번 눌러도 기억 기록은 한 건이어야 합니다. 편집 중 새로고침하면 초안만 원문으로 돌아와야 합니다.
9. 처음의 두 대화 선택을 바꿔 플레이하면 마지막에 그 선택을 기억하는 대사가 달라지는지 확인합니다.
10. 1280×720, 1920×1080, 좁은 창에서 버튼 접근, 긴 문장 줄바꿈, 페이지 스크롤을 확인합니다. 브라우저 Console 오류와 SVG 로드 실패가 없어야 합니다.

| 단어 선택 | 문장 유지 시 | 문장 삭제 시 |
| --- | --- | --- |
| 우연 | 예민했던 것 같다는 대사 → 두려움이 남음 | 같은 우연 대사 → 무엇을 두려워했는지 잊음 |
| 계시 | 의미가 있었던 것 같다는 대사 → 두려움이 남음 | 같은 계시 대사 → 두려움의 기억이 비어 있음 |
| 착각 | 착각이었을지도 모른다는 대사 → 두려움이 남음 | 같은 착각 대사 → 두려움의 기억이 비어 있음 |

## 저장 정책과 제한

키: `nyarlathotep-vn.save.v1`, 저장 구조 버전 1, 콘텐츠 버전 `confession-1`. 브라우저별 단일 슬롯이며 계정 서버에는 저장하지 않습니다. 이전 공개 버전에는 저장 시스템이 없었습니다.

손상·미지원 저장은 자동 덮어쓰지 않고 오류를 표시합니다. 저장 차단·용량 초과 시 메모리 플레이는 계속되며 저장 재시도가 가능합니다. 저장 실패 안내가 보이면 새로고침 전에 해결하세요. 테스트로 저장을 수정할 때는 해당 게임 키만 백업·조작하며 다른 사이트 저장을 지우지 마세요. 여러 탭 동시 플레이의 저장 병합은 지원하지 않습니다.

복잡한 심리 수치, 장기 루트, 다중 엔딩, 자유 입력은 미구현입니다.

## 콘텐츠와 코드

- `src/content/scenarios/intro.json`: 캐릭터, flagKeys, 대화·고해성사, 선택 효과, 조건 분기.
- `src/content/mind-scenes/bells.json`: 사고 이벤트와 문장/구간/옵션/결과 ID, 상태 효과.
- `src/domain/scenario.ts`, `flags.ts`: 순수 데이터 검증·진행·플래그 계산.
- `src/domain/mind/editing.ts`: 순수 편집 검증·초안·결과 계산. React와 저장소에 의존하지 않습니다.
- `src/store/gameStore.ts`: Zustand 상태와 전이. 중복 확정·오래된 세션 입력을 차단합니다.
- `src/services/storage.ts`: 저장·복원 및 버전·참조 검사.
- `src/screens/MindEditScreen.tsx`: 별도 정신 침투 화면과 임시 편집 상태.

세부 데이터 계약은 `docs/TECH_STACK.md`의 현재 구현 절을 참고합니다. 신규 캐릭터/이벤트도 같은 엔진을 사용하며 App의 콘텐츠 로더에 JSON을 연결합니다. 원본 JSON을 실행 상태로 변이시키지 않습니다.

TypeScript 검사 및 Vite 빌드 통과. 실제 브라우저 도구가 없는 환경이므로 화면 클릭·시각 배치 검수는 미수행입니다. 자동 테스트의 새 store 생성은 저장 복원 로직 검증이며 실제 브라우저 새로고침 검수와 구분합니다.
